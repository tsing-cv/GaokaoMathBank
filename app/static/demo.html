📄 题目卡片

函数 2023 全国I卷 · 第2题
已知函数 $f(x) = x^3 - 3x + 1$，则 $f(x)$ 在区间 $[-2, 2]$ 上的最大值为：
A. $f(-2) = 3$
B. $f(0) = 1$
C. $f(1) = -1$
D. $f(2) = 3$
查看答案与解析
答案： D

解析： 求导得 $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$，令 $f'(x) = 0$ 得 $x = -1$ 或 $x = 1$。

计算各点函数值：$f(-2) = 3$，$f(-1) = 3$，$f(1) = -1$，$f(2) = 3$。

因此最大值为 $3$，选 D。
