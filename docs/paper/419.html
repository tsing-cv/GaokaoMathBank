2009年四川卷（理）

2009年 · 四川 · 理科 · 真题 · 共 16 题

  1. 选择题 集合与逻辑
    设集合$S = \{x \mid |x| < 5\}$，$T = \{x \mid x^2 + 4x - 21 < 0\}$，则$S \cap T =$（ ）
    A.
    $\{x\mid -7 < x < -5\}$
    B.
    $\{x\mid 3 < x < 5\}$
    C.
    $\{x\mid -5 < x < 3\}$
    D.
    $\{x\mid -7 < x < 5\}$
    显示答案
    答案:
    C
    解析:
    由绝对值不等式，$|x|<5$等价于$-5<x<5$，故$S=(-5,5)$. 又$x^2+4x-21=(x+7)(x-3)$，二次项系数为正，所以$x^2+4x-21<0$的解为$-7<x<3$，即$T=(-7,3)$. 因而$S\cap T=(-5,3)$，对应选项 C。
  2. 选择题 函数
    已知函数$f(x) = \begin{cases} a + \log_2 x & \text{当 } x \geqslant 2 \text{ 时}\\ \frac{x^2 - 4}{x - 2} & \text{当 } x < 2 \text{ 时} \end{cases}$在点$x = 2$处连续，则常数$a$的值是（ ）
    A.
    $2$
    B.
    $3$
    C.
    $4$
    D.
    $5$
    显示答案
    答案:
    B
    解析:
    当$x<2$时，$\dfrac{x^2-4}{x-2}=x+2$，所以$\displaystyle\lim_{x\to2^-}f(x)=4$. 又$f(2)=a+\log_2 2=a+1$. 由连续性，$a+1=4$，解得$a=3$，故选 B。
  3. 选择题 复数
    复数$\frac{(1 + 2i)^2}{3 - 4i}$的值是（ ）
    A.
    $-1$
    B.
    $1$
    C.
    $-i$
    D.
    $i$
    显示答案
    答案:
    A
    解析:
    $(1+2i)^2=1+4i+4i^2=-3+4i=-(3-4i)$. 因为分母$3-4i\ne0$，所以$\dfrac{(1+2i)^2}{3-4i}=-1$，对应选项 A。
  4. 选择题 立体几何
    如图，已知六棱锥$P - ABCDEF$的底面是正六边形，$PA \perp$平面$ABC$，$PA = 2AB$，则下列结论正确的是（ ）
    A.
    $PB \perp AD$
    B.
    平面$PAB \perp$平面$PBC$
    C.
    直线$BC \parallel$平面$PAE$
    D.
    直线$PD$与平面$ABC$所成的角为$45^{\circ}$
    显示答案
    答案:
    D
    解析:
    设正六边形的边长为$s$，取底面为$z=0$，令$A=(s,0,0)$，$B=\left(\dfrac{s}{2},\dfrac{\sqrt{3}s}{2},0\right)$，$C=\left(-\dfrac{s}{2},\dfrac{\sqrt{3}s}{2},0\right)$，$D=(-s,0,0)$，$E=\left(-\dfrac{s}{2},-\dfrac{\sqrt{3}s}{2},0\right)$，并由$PA\perp$平面$ABC$及$PA=2s$取$P=(s,0,2s)$. 则$\overrightarrow{PB}=\left(-\dfrac{s}{2},\dfrac{\sqrt{3}s}{2},-2s\right)$，$\overrightarrow{AD}=(-2s,0,0)$，二者数量积为$s^2\ne0$，故 A 错. 平面$PAB$、$PBC$的法向量可分别取$(\sqrt{3},1,0)$、$(0,2,\sqrt{3})$，其数量积为$2\ne0$，故 B 错. 平面$PAE$的法向量可取$(\sqrt{3},-3,0)$，而$\overrightarrow{BC}=(-s,0,0)$与该法向量数量积不为零，故 C 错. 最后，$\overrightarrow{PD}=(-2s,0,-2s)$，它在平面$ABC$上的投影长度为$2s$，垂直分量的长度也为$2s$，所以直线$PD$与平面$ABC$所成的角为$45^{\circ}$，故选 D。
  5. 选择题 立体几何
    如图，在半径为 3 的球面上有$A$，$B$，$C$三点，$\angle ABC = 90^{\circ}$，$BA = BC$，球心$O$到平面$ABC$的距离是$\frac{3\sqrt{2}}{2}$，则$B$，$C$两点的球面距离是（ ）
    A.
    $\frac{\pi}{3}$
    B.
    $\pi$
    C.
    $\frac{4\pi}{3}$
    D.
    $2\pi$
    显示答案
    答案:
    B
    解析:
    设$H$为球心$O$在平面$ABC$上的射影. 平面截球所得圆的半径为$r=\sqrt{3^2-\left(\dfrac{3\sqrt{2}}{2}\right)^2}=\dfrac{3\sqrt{2}}{2}$. 由于$\angle ABC=90^{\circ}$，三角形$ABC$的外心是斜边$AC$的中点； 又$BA=BC$，所以其外接圆半径为$\dfrac{BC}{\sqrt{2}}$. 因此$\dfrac{BC}{\sqrt{2}}=\dfrac{3\sqrt{2}}{2}$，得$BC=3$. 设较短的球面大圆弧$BC$所对的较小球心角为$\theta$. 由弦长公式$BC=2\cdot3\sin\dfrac{\theta}{2}$，得$\sin\dfrac{\theta}{2}=\dfrac12$，故$\theta=\dfrac{\pi}{3}$. 球面距离为相应大圆弧长，即$3\theta=\pi$，故选 B。
  6. 选择题 解析几何
    已知直线$l_1: 4x - 3y + 6 = 0$和直线$l_2: x = -1$，抛物线$y^2 = 4x$上一动点$P$到直线$l_1$和直线$l_2$的距离之和的最小值是（ ）
    A.
    $2$
    B.
    $3$
    C.
    $\frac{11}{5}$
    D.
    $\frac{37}{16}$
    显示答案
    答案:
    A
    解析:
    设抛物线上动点$P=(t^2,2t)$，其中$t\in\R$. 点$P$到$l_1$的距离为$\dfrac{|4t^2-3\cdot2t+6|}{\sqrt{4^2+(-3)^2}}$. 由于$4t^2-6t+6=4\left(t-\dfrac34\right)^2+\dfrac{15}{4}>0$，该距离为$\dfrac{4t^2-6t+6}{5}$； 点$P$到$l_2:x=-1$的距离为$t^2+1$. 所以距离之和为$\dfrac{4t^2-6t+6}{5}+t^2+1=\dfrac{9t^2-6t+11}{5}=\dfrac{9\left(t-\frac13\right)^2+10}{5}\geqslant2$. 当$t=\dfrac13$时$P$在抛物线上且等号成立，因此最小值为$2$，对应选项 A。
  7. 选择题 待标注
    3位男生和3位女生共6位同学站成一排，若男生甲不站两端，3位女生中有且只有两位女生相邻，则不同排法的种数是（ ）
    A.
    $360$
    B.
    $188$
    C.
    $216$
    D.
    $96$
    显示答案
    答案:
    题面选项有误，正确计数为$288$（若将 B 项修正为$288$，则选 B）。
    解析:
    先将三位男生排好，记四个空隙依次为$G_0$，$G_1$，$G_2$，$G_3$，其中$G_0$在首位男生前，$G_1$、$G_2$在相邻两位男生之间，$G_3$在末位男生后. 恰有两位女生相邻时，三位女生必须放入两个空隙，且两个空隙中的女生数分别为$2$和$1$； 同一空隙中的两位女生相邻，另一个空隙中的女生与她们之间隔着男生. 女生在确定位置上的排列共有$3!$种. 分类讨论两个非空隙的位置. 若两个非空隙为$G_1$、$G_2$，两端都是男生，男生甲只能站中间，男生有$2$种排法； 女生数目的分配有$2$种. 若恰有一个端点空隙非空，非空隙的组合有$2\times2=4$种，女生数目的分配有$2$种，且恰有一个男生站在队伍端点，男生甲不能站该端点，男生有$3! -2! =4$种排法. 若两个端点空隙$G_0$、$G_3$都非空，女生数目的分配有$2$种，男生不站队伍两端，男生有$3! =6$种排法. 因此排法总数为$\left(2\cdot2+4\cdot2\cdot4+2\cdot6\right)\cdot3! =288$所以按原题面计数，结果为$288$. 但原题面的选项为$360$、$188$、$216$、$96$，其中没有$288$，故无法给出与原选项一致的选项字母。
  8. 填空题 导数
    若$\odot O_1: x^{2} + y^{2} = 5$与$\odot O_2: (x - m)^{2} + y^{2} = 20$（$m \in \R$）相交于$A$，$B$两点，且两圆在点$A$处的切线互相垂直，则线段$AB$的长度是____。
    显示答案
    答案:
    $4$
    解析:
    两圆半径分别为$r_1=\sqrt{5}$、$r_2=2\sqrt{5}$. 在点$A$处两圆切线垂直，等价于半径$O_1A\perp O_2A$，所以在直角三角形$O_1AO_2$中，$O_1O_2^2=r_1^2+r_2^2=25$，即$O_1O_2=5$. 设公共弦$AB$与连心线交于$H$. 由两圆相交弦的连心线关系，$O_1H=\dfrac{r_1^2-r_2^2+O_1O_2^2}{2O_1O_2}=\dfrac{5-20+25}{10}=1$. 在直角三角形$O_1HA$中，$HA=\sqrt{r_1^2-O_1H^2}=\sqrt{5-1}=2$，故$AB=2HA=4$。
  9. 填空题 立体几何
    如图，已知正三棱柱$ABC - A_{1}B_{1}C_{1}$的各条棱长都相等，$M$是侧棱$CC_{1}$的中点，则异面直线$AB_{1}$和$BM$所成的角的大小是____。
    显示答案
    答案:
    $90^{\circ}$
    解析:
    设棱长为$s$，建立直角坐标系，取$A=(0,0,0)$，$B=(s,0,0)$，$C=\left(\dfrac{s}{2},\dfrac{\sqrt{3}s}{2},0\right)$，并令竖直方向为第三坐标轴. 则$B_1=(s,0,s)$，$M=\left(\dfrac{s}{2},\dfrac{\sqrt{3}s}{2},\dfrac{s}{2}\right)$. 于是可取$\overrightarrow{AB_1}=(s,0,s)$，$\overrightarrow{BM}=\left(-\dfrac{s}{2},\dfrac{\sqrt{3}s}{2},\dfrac{s}{2}\right)$，二者数量积为$-\dfrac{s^2}{2}+\dfrac{s^2}{2}=0$. 所以两异面直线所成的角为$90^{\circ}$。
  10. 填空题 集合与逻辑 · 向量
    设$V$是已知平面$M$上所有向量的集合. 对于映射$f: V \to V$，$\mathbf{a} \in V$，记$\mathbf{a}$的象为$f(\mathbf{a})$. 若映射$f: V \to V$满足：对所有$\mathbf{a}$，$\mathbf{b} \in V$及任意实数$\lambda$，$\mu$都有$f(\lambda\mathbf{a} + \mu\mathbf{b}) = \lambda f(\mathbf{a}) + \mu f(\mathbf{b})$，则$f$称为平面$M$上的线性变换. 现有下列命题： ① 设$f$是平面$M$上的线性变换，则$f(0) = 0$； ② 对$\mathbf{a} \in V$，设$f(\mathbf{a}) = 2\mathbf{a}$，则$f$是平面$M$上的线性变换； ③ 若$\mathbf{e}$是平面$M$上的单位向量，对$\mathbf{a} \in V$，设$f(\mathbf{a}) = \mathbf{a} - \mathbf{e}$，则$f$是平面$M$上的线性变换； ④ 设$f$是平面$M$上的线性变换，$\mathbf{a}$，$\mathbf{b} \in V$，若$\mathbf{a}$，$\mathbf{b}$共线，则$f(\mathbf{a})$，$f(\mathbf{b})$也共线. 其中真命题是____.（写出所有真命题的序号）
    显示答案
    答案:
    $1$、$2$、$4$
    解析:
    命题 1：由线性变换的定义，$f(0)=f(0\mathbf{a}+0\mathbf{b})=0f(\mathbf{a})+0f(\mathbf{b})=0$，故命题 1 正确. 命题 2：若$f(\mathbf{a})=2\mathbf{a}$，则对任意$\lambda$、$\mu$有$f(\lambda\mathbf{a}+\mu\mathbf{b})=2\lambda\mathbf{a}+2\mu\mathbf{b}=\lambda f(\mathbf{a})+\mu f(\mathbf{b})$，故命题 2 正确. 命题 3：$f(0)=-\mathbf{e}\ne0$，不满足线性变换必须满足的$f(0)=0$，故命题 3 错误. 命题 4：若$\mathbf{a}=0$或$\mathbf{b}=0$，则$f(\mathbf{a})=0$或$f(\mathbf{b})=0$，两向量共线. 若$\mathbf{a}\ne0$，由$\mathbf{a}$、$\mathbf{b}$共线，存在实数$k$使$\mathbf{b}=k\mathbf{a}$，于是$f(\mathbf{b})=f(k\mathbf{a})=kf(\mathbf{a})$，所以$f(\mathbf{a})$、$f(\mathbf{b})$共线，命题 4 正确. 因此真命题的序号为 1、2、4。
  11. 解答题 三角函数
    在$\triangle ABC$中，$A$，$B$为锐角，角$A$，$B$，$C$所对应的边分别为$a$，$b$，$c$，且$\cos 2A = \frac{3}{5}$，$\sin B = \frac{\sqrt{10}}{10}$. (1) 求$A + B$的值； (2) 若$a - b = \sqrt{2} - 1$，求$a$，$b$，$c$的值。
    显示答案
    解析:
    (1) 因为$A$为锐角，所以由$\cos 2A=\dfrac35$得$\cos^2A=\dfrac{1+\cos2A}{2}=\dfrac45$，从而$\cos A=\dfrac{2\sqrt5}{5}$，$\sin A=\dfrac{\sqrt5}{5}$. 又因$B$为锐角且$\sin B=\dfrac{\sqrt{10}}{10}$，故$\cos B=\dfrac{3\sqrt{10}}{10}$. 因此$\sin(A+B)=\dfrac{\sqrt5}{5}\cdot\dfrac{3\sqrt{10}}{10}+\dfrac{2\sqrt5}{5}\cdot\dfrac{\sqrt{10}}{10}=\dfrac{\sqrt2}{2}$，$\cos(A+B)=\dfrac{2\sqrt5}{5}\cdot\dfrac{3\sqrt{10}}{10}-\dfrac{\sqrt5}{5}\cdot\dfrac{\sqrt{10}}{10}=\dfrac{\sqrt2}{2}$. 由于$0<A+B<\pi$，所以$A+B=\dfrac{\pi}{4}$. (2) 由正弦定理，$a:b=\sin A:\sin B=\sqrt2:1$. 设$a=\sqrt2t$，$b=t$，则$a-b=t(\sqrt2-1)=\sqrt2-1$，所以$t=1$，即$a=\sqrt2$，$b=1$. 又$C=\pi-(A+B)=\dfrac{3\pi}{4}$，再次由正弦定理得$c=b\dfrac{\sin C}{\sin B}=\dfrac{\frac{\sqrt2}{2}}{\frac{\sqrt{10}}{10}}=\sqrt5$。
  12. 解答题 概率统计
    为振兴旅游业，四川省 2009 年面向国内发行总量为$2000\text{ 万张}$的熊猫优惠卡，向省外人士发行的是熊猫金卡（简称金卡），向省内人士发行的是熊猫银卡（简称银卡）. 某旅游公司组织了一个有$36$名游客的旅游团到四川名胜旅游，其中$\frac{3}{4}$是省外游客，其余是省内游客. 在省外游客中有$\frac{1}{3}$持金卡，在省内游客中有$\frac{2}{3}$持银卡. (1) 在该团中随机采访$3$名游客，求恰有$1$人持金卡且持银卡者少于$2$人的概率； (2) 在该团的省内游客中随机采访$3$名游客，设其中持银卡人数为随机变量$\xi$，求$\xi$的分布列及数学期望$E(\xi)$。
    显示答案
    解析:
    (1) 省外游客有$36\cdot\dfrac34=27$人，其中持金卡的有$9$人； 省内游客有$9$人，其中持银卡的有$6$人. 因而全团有$9$人持金卡，$6$人持银卡，另有$21$人不持这两种卡. 所求事件分为“恰有$1$人持金卡且无持银卡者”和“恰有$1$人持金卡、$1$人持银卡”两类，故概率为$\dfrac{\mathrm C_9^1\mathrm C_{21}^2+\mathrm C_9^1\mathrm C_6^1\mathrm C_{21}^1}{\mathrm C_{36}^3}=\dfrac{36}{85}$. (2) 省内游客中有$6$人持银卡、$3$人不持银卡，因此$\xi$服从不放回抽样的超几何分布. 对$k=0$，$1$，$2$，$3$，有$P(\xi=k)=\dfrac{\mathrm C_6^k\mathrm C_3^{3-k}}{\mathrm C_9^3}$，所以$P(\xi=0)=\dfrac1{84}$，$P(\xi=1)=\dfrac3{14}$，$P(\xi=2)=\dfrac{15}{28}$，$P(\xi=3)=\dfrac5{21}$. 数学期望为$E(\xi)=3\cdot\dfrac69=2$。
  13. 解答题 三角函数 · 立体几何
    如图，正方形$ABCD$所在平面与平面四边形$ABEF$所在平面互相垂直，$\triangle ABE$是等腰直角三角形，$AB = AE$，$FA = FE$，$\angle AEF = 45^{\circ}$. (1) 求证：$EF \perp$平面$BCE$； (2) 设线段$CD$的中点为$P$，在直线$AE$上是否存在一点$M$，使得$PM \parallel$平面$BCE$？若存在，请指出点$M$的位置，并证明你的结论；若不存在，请说明理由； (3) 求二面角$F - BD - A$的大小。
    显示答案
    解析:
    取$AB=s$，建立直角坐标系，使正方形所在平面为$z=0$，令$A=(0,0,0)$，$B=(s,0,0)$，$C=(s,s,0)$，$D=(0,s,0)$. 两平面互相垂直且交线为$AB$，又$\triangle ABE$是以$A$为直角顶点的等腰直角三角形，故可取$E=(0,0,s)$. 由$FA=FE$，三角形$AEF$的底角相等，所以$\angle FAE=\angle AEF=45^{\circ}$，从而$\angle AFE=90^{\circ}$. 在平面$y=0$内结合这两个角，取与图形位置一致的$F=\left(-\dfrac{s}{2},0,\dfrac{s}{2}\right)$. (1)$\overrightarrow{BC}=(0,s,0)$，$\overrightarrow{BE}=(-s,0,s)$，所以平面$BCE$的一个法向量为$(1,0,1)$. 而$\overrightarrow{EF}=\left(-\dfrac{s}{2},0,-\dfrac{s}{2}\right)$与此法向量平行，因此$EF\perp$平面$BCE$. (2) 线段$CD$的中点为$P=\left(\dfrac{s}{2},s,0\right)$. 设直线$AE$上的点为$M=(0,0,t)$，则$\overrightarrow{PM}=\left(-\dfrac{s}{2},-s,t\right)$. 由上知平面$BCE$的一个法向量为$(1,0,1)$，要使$PM\parallel$平面$BCE$，必须有$\overrightarrow{PM}\cdot(1,0,1)=t-\dfrac{s}{2}=0$，故$t=\dfrac{s}{2}$. 此时$M=\left(0,0,\dfrac{s}{2}\right)$是线段$AE$的中点，且平面$BCE$的方程为$x+z=s$，点$P$不在该平面内，所以$PM\parallel$平面$BCE$. 因而存在这样的点$M$，且它是线段$AE$的中点. (3) 平面$ABD$的法向量可取$\mathbf{n}_1=(0,0,1)$. 在平面$FBD$中，$\overrightarrow{BD}=(-s,s,0)$，$\overrightarrow{BF}=\left(-\dfrac{3s}{2},0,\dfrac{s}{2}\right)$，故其法向量可取$\mathbf{n}_2=(1,1,3)$. 设二面角$F-BD-A$的大小为$\theta$，则$\cos\theta=\dfrac{|\mathbf{n}_1\cdot\mathbf{n}_2|}{|\mathbf{n}_1||\mathbf{n}_2|}=\dfrac{3}{\sqrt{11}}$，所以$\theta=\arccos\dfrac{3}{\sqrt{11}}$。
  14. 解答题 解析几何
    已知椭圆$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$）的左，右焦点分别为$F_1$，$F_2$，离心率$e = \frac{\sqrt{2}}{2}$，右准线方程为$x = 2$. (1) 求椭圆的标准方程； (2) 过点$F_{1}$的直线$l$与该椭圆交于$M$，$N$两点，且$\left|\overrightarrow{F_2M} + \overrightarrow{F_2N}\right| = \frac{2\sqrt{26}}{3}$，求直线$l$的方程。
    显示答案
    解析:
    (1) 设椭圆半焦距为$c$. 右准线方程为$x=\dfrac{a}{e}=2$，所以$a=2e=\sqrt2$，又$c=ae=1$. 由$b^2=a^2-c^2$得$b^2=1$，故椭圆的标准方程为$\dfrac{x^2}{2}+y^2=1$. (2) 由上知$F_1=(-1,0)$，$F_2=(1,0)$. 先考虑非竖直直线，设其方程为$y=k(x+1)$. 将其代入椭圆方程，得$(1+2k^2)x^2+4k^2x+2k^2-2=0$. 若交点$M$、$N$的横坐标为$x_1$、$x_2$，则$x_1+x_2=-\dfrac{4k^2}{1+2k^2}$，且$y_1+y_2=k(x_1+x_2+2)=\dfrac{2k}{1+2k^2}$. 因此$\overrightarrow{F_2M}+\overrightarrow{F_2N}=(x_1+x_2-2,y_1+y_2)$，从而$\left|\overrightarrow{F_2M}+\overrightarrow{F_2N}\right|^2=\dfrac{4(1+9k^2+16k^4)}{(1+2k^2)^2}$. 令$u=k^2$，代入题设长度得$\dfrac{4(1+9u+16u^2)}{(1+2u)^2}=\dfrac{104}{9}$，化简为$40u^2-23u-17=0$. 因为$u\geqslant0$，所以$u=1$，即$k=\pm1$. 竖直直线$x=-1$时，向量和的长度为$4$，不满足题设条件. 故直线$l$的方程为$y=x+1$或$y=-x-1$。
  15. 解答题 函数 · 导数
    已知$a > 0$，且$a \neq 1$，函数$f(x) = \log_a(1 - a^x)$. (1) 求函数$f(x)$的定义域，并判断$f(x)$的单调性； (2) 若$n \in \N^*$，求$\displaystyle\lim_{n \to +\infty} \frac{a^{f(n)}}{a^n + a}$； (3) 当$a = e$（$e$为自然对数的底数）时，设$h(x) = (1 - e^{f(x)})(x^2 - m + 1)$. 若函数$h(x)$的极值存在，求实数$m$的取值范围以及函数$h(x)$的极值。
    显示答案
    解析:
    (1) 由对数真数为正，需有$1-a^x>0$. 当$0<a<1$时，$a^x<1$等价于$x>0$，定义域为$(0,+\infty)$； 当$a>1$时，$a^x<1$等价于$x<0$，定义域为$(-\infty,0)$. 在定义域内，$f'(x)=\dfrac{-a^x\ln a}{(1-a^x)\ln a}=-\dfrac{a^x}{1-a^x}<0$，所以$f(x)$在各自定义域上都是减函数. (2) 第（2）问中的$f(n)$对每个正整数$n$有定义时必须是$0<a<1$. 此时由定义有$a^{f(n)}=1-a^n$，故$\displaystyle\lim_{n\to+\infty}\dfrac{a^{f(n)}}{a^n+a}=\displaystyle\lim_{n\to+\infty}\dfrac{1-a^n}{a^n+a}=\dfrac1a$. 当$a>1$时，正整数不在定义域内，原极限表达式没有实数意义. (3) 当$a=e$时，定义域为$x<0$，且$e^{f(x)}=1-e^x$，所以$h(x)=e^x(x^2-m+1)$. 求导得$h'(x)=e^x(x^2+2x-m+1)=e^x\bigl((x+1)^2-m\bigr)$. 若$m\leqslant0$，则在$x<0$上没有发生正负变化的临界点，函数没有极值； 若$m>0$，临界点为$x_1=-1-\sqrt m$以及$x_2=-1+\sqrt m$. 当$0<m<1$时，两个临界点都在定义域内，$x_1$处为极大值点，$x_2$处为极小值点，且极大值为$2e^{-1-\sqrt m}(1+\sqrt m)$，极小值为$2e^{-1+\sqrt m}(1-\sqrt m)$. 当$m\geqslant1$时，只有$x_1$在定义域内，故只有极大值，极大值为$2e^{-1-\sqrt m}(1+\sqrt m)$. 因而极值存在时$m\in(0,+\infty)$。
  16. 解答题 导数 · 数列
    设数列$\{a_{n}\}$的前$n$项和为$S_{n}$，对任意的正整数$n$，都有$a_{n} = 5S_{n} + 1$成立，记$b_{n} = \frac{4 + a_{n}}{1 - a_{n}}$（$n \in \N^*$）. (1) 求数列$\{b_{n}\}$的通项公式； (2) 记$c_{n} = b_{2n} - b_{2n-1}$（$n \in \N^*$），设数列$\{c_{n}\}$的前$n$项和为$T_{n}$，求证：对任意正整数$n$都有$T_{n} < \frac{3}{2}$； (3) 设数列$\{b_{n}\}$的前$n$项和为$R_{n}$. 已知正实数$\lambda$满足：对任意正整数$n$，$R_{n} \leqslant \lambda n$恒成立，求$\lambda$的最小值。
    显示答案
    解析:
    (1) 取$n=1$，由$a_1=5S_1+1$得$a_1=-\dfrac14$. 当$n\geqslant2$时，将$a_n=5S_n+1$与$a_{n-1}=5S_{n-1}+1$相减，得$a_n-a_{n-1}=5a_n$，所以$a_n=-\dfrac14a_{n-1}$. 因而$a_n=\left(-\dfrac14\right)^n$. 代入定义，得到$b_n=\dfrac{4+\left(-\dfrac14\right)^n}{1-\left(-\dfrac14\right)^n}$. (2) 令$t_n=16^{-n}$，则$\left(-\dfrac14\right)^{2n}=t_n$，$\left(-\dfrac14\right)^{2n-1}=-4t_n$. 因此$c_n=b_{2n}-b_{2n-1}=\dfrac{4+t_n}{1-t_n}-\dfrac{4-4t_n}{1+4t_n}=\dfrac{25t_n}{(1-t_n)(1+4t_n)}$. 当$n=1$时，$c_1=\dfrac43$. 当$n\geqslant2$时，$(1-t_n)(1+4t_n)>1$，所以$0<c_n<\dfrac{25}{16^n}$. 对任意正整数$n$，有$T_n<\dfrac43+\sum_{k=2}^{\infty}\dfrac{25}{16^k}=\dfrac43+\dfrac5{48}=\dfrac{23}{16}<\dfrac32$. (3) 由$b_{2k-1}<4$，并且令$t=16^{-k}$可得$b_{2k}+b_{2k-1}-8=\dfrac{5t(8t-3)}{(1-t)(1+4t)}<0$，所以$b_{2k}+b_{2k-1}<8$. 因此当$n=2m$时，$R_n<8m=4n$； 当$n=1$时，$R_1=b_1<4$； 当$n=2m-1\geqslant3$时，$R_n=R_{2m-2}+b_{2m-1}<8(m-1)+4<4(2m-1)=4n$. 故$\lambda=4$满足条件. 另一方面，$b_n\to4$，由数列平均值也有$\dfrac{R_n}{n}\to4$. 若$\lambda<4$，则对充分大的$n$有$R_n/n>\lambda$，与题设不符. 所以$\lambda$的最小值为$4$。
