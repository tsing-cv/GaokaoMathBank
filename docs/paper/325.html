  1. 选择题 复数
    复数$\left(\frac\{2i\}\{1 + i\}\right)^2$等于（ ）
    A.
    $4i$
    B.
    $-4i$
    C.
    $2i$
    D.
    $-2i$
    显示答案
    答案:
    C
    解析:
    由$\frac\{2i\}\{1+i\}=\frac\{2i(1-i)\}\{(1+i)(1-i)\}=\frac\{2i(1-i)\}\{2\}=1+i$. 因此$\left(\frac\{2i\}\{1+i\}\right)^2=(1+i)^2=1+2i+i^2=2i$， 故选 C。
  2. 选择题 不等式
    不等式$\frac\{x - 2\}\{x + 1\} \leqslant 0$的解集是（ ）
    A.
    $(-\infty, -1) \cup (-1, 2]$
    B.
    $[-1, 2]$
    C.
    $(-\infty, -1) \cup [2, +\infty)$
    D.
    $(-1, 2]$
    显示答案
    答案:
    D
    解析:
    不等式的分界点为$x=-1$和$x=2$，其中$x=-1$使分母为零，不能取. 当$x<-1$时，$\frac\{x-2\}\{x+1\}>0$； 当$-12$时，$\frac\{x-2\}\{x+1\}>0$. 当$x=2$时分式等于零，可以取. 所以解集为$(-1,2]$，故选 D。
  3. 选择题 集合与逻辑
    设$M$，$N$是两个集合，则$M \cup N \neq \emptyset$是“$M \cap N \neq \emptyset$”的（ ）
    A.
    充分不必要条件
    B.
    必要不充分条件
    C.
    充分必要条件
    D.
    既不充分又不必要条件
    显示答案
    答案:
    B
    解析:
    若$M\cap N\neq\emptyset$，则存在元素同时属于$M$和$N$，从而该元素属于$M\cup N$，所以$M\cup N\neq\emptyset$. 因此“$M\cup N\neq\emptyset$”是“$M\cap N\neq\emptyset$”的必要条件. 但取$M=\{1\}$，$N=\{2\}$，则$M\cup N\neq\emptyset$，而$M\cap N=\emptyset$，故必要条件不充分. 所以选 B。
  4. 选择题 函数 · 向量
    设$\mathbf\{a\}$，$\mathbf\{b\}$是非零向量，若函数$f(x) = (x\mathbf\{a\} + \mathbf\{b\}) \cdot (\mathbf\{a\} - x\mathbf\{b\})$的图象是一条直线，则必有（ ）
    A.
    $\mathbf\{a\} \perp \mathbf\{b\}$
    B.
    $\mathbf\{a\} \parallel \mathbf\{b\}$
    C.
    $|\mathbf\{a\}| = |\mathbf\{b\}|$
    D.
    $|\mathbf\{a\}| \neq |\mathbf\{b\}|$
    显示答案
    答案:
    A
    解析:
    展开函数式得$f(x)=(x\mathbf\{a\}+\mathbf\{b\})\cdot(\mathbf\{a\}-x\mathbf\{b\})=-\left(\mathbf\{a\}\cdot\mathbf\{b\}\right)x^2+\left(|\mathbf\{a\}|^2-|\mathbf\{b\}|^2\right)x+\mathbf\{a\}\cdot\mathbf\{b\}$函数图象是一条直线，故二次项系数必须为零，即$\mathbf\{a\}\cdot\mathbf\{b\}=0$. 由于$\mathbf\{a\}$，$\mathbf\{b\}$均为非零向量，所以$\mathbf\{a\}\perp\mathbf\{b\}$，故选 A。
  5. 选择题 待标注
    设随机变量$\xi$服从标准正态分布$N(0,1)$. 已知$\Phi(-1.96) = 0.025$，则$P(|\xi| < 1.96) =$（ ）
    A.
    0.025
    B.
    0.050
    C.
    0.950
    D.
    0.975
    显示答案
    答案:
    C
    解析:
    由标准正态分布的对称性，$\Phi(1.96)=1-\Phi(-1.96)=0.975$. 因此$P(|\xi|<1.96)=P(-1.96<\xi<1.96)=\Phi(1.96)-\Phi(-1.96)=0.975-0.025=0.950$. 故选 C。

    函数$f(x) = 12x - x^3$在区间$[-3, 3]$上的最小值是____。
    显示答案
    答案:

    解析:

  12. 填空题 集合与逻辑
    设集合$A = \left\{(x, y) \mid y \geqslant \frac\{1\}\{2\} |x - 2|\right\}$，$B = \{(x, y) \mid y \leqslant -|x| + b\}$，$A \cap B \neq \emptyset$. (1)$b$的取值范围是____； (2) 若$(x, y) \in A \cap B$，且$x + 2y$的最大值为$9$，则$b$的值是____。
    显示答案
    答案:
    第一空：$[1,+\infty)$；第二空：$\frac{9}{2}$
    解析:
    由$A\cap B\neq\emptyset$，存在实数$x$和$y$使$\frac\{1\}\{2\}|x-2|\leqslant y\leqslant -|x|+b$因此必须且只需$b\geqslant |x|+\frac\{1\}\{2\}|x-2|$对某个实数$x$成立. 分三种情况讨论： 当$x\leqslant0$时，$|x|+\frac\{1\}\{2\}|x-2|=-x+\frac\{1\}\{2\}(2-x)=1-\frac\{3\}\{2\}x\geqslant1;$当$0\leqslant x\leqslant2$时，$|x|+\frac\{1\}\{2\}|x-2|=x+\frac\{1\}\{2\}(2-x)=1+\frac\{1\}\{2\}x\geqslant1;$当$x\geqslant2$时，$|x|+\frac\{1\}\{2\}|x-2|=x+\frac\{1\}\{2\}(x-2)=\frac\{3\}\{2\}x-1\geqslant2$所以该式的最小值为$1$，第一空为$b\in[1,+\infty)$. 在$A\cap B$中，固定$x$时$x+2y$随$y$增大而增大，故可取$y=-|x|+b$. 于是$x+2y=2b+x-2|x|$当$x\leqslant0$时，$x-2|x|=3x\leqslant0$； 当$x\geqslant0$时，$x-2|x|=-x\leqslant0$. 因此最大值在$x=0$处取得，且最大值为$2b$. 由题设$2b=9$，得第二空为$b=\frac\{9\}\{2\}$。

    显示答案
    答案:
    第一空：$2^n-1$；第二空：$32$
    解析:
    第$r$行的数是二项式系数$\mathrm C_r^0$，$\ \mathrm C_r^1$，$\ \ldots$，$\ \mathrm C_r^r$的奇偶性. 设$r$的二进制表示中有$s$个数位为$1$，则在模$2$意义下$(1+x)^r\equiv\prod_\{j=1\}^\{s\}\left(1+x^\{2^\{t_j\}\}\right)$其中$r=2^\{t_1\}+2^\{t_2\}+\cdots+2^\{t_s\}$. 右端展开后有$2^s$个不同的项，故第$r$行中$1$的个数为$2^s$. 第$r$行全为$1$当且仅当$r$的二进制表示各数位均为$1$，即$r=2^m-1$. 因此第$n$次出现全为$1$的行是第$2^n-1$行. 又$61=(111101)_2$，其中有$5$个数位为$1$，所以第$61$行中$1$的个数为$2^5=32$。
