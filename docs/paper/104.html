  1. 选择题 函数
    函数$y = (0.2)^\{-x\} + 1$的反函数是（ ）
    A.
    $y = \log_5 (x + 1)$
    B.
    $y = \log_x 5 + 1$
    C.
    $y = \log_5 (x - 1)$
    D.
    $y = \log_5 x - 1$
    显示答案
    答案:
    C
    解析:
    因为$0.2=\frac\{1\}\{5\}$，所以$0.2^\{-x\}=5^x$，原函数可写为$y=5^x+1$. 于是$y-1=5^x$，从而$x=\log_5(y-1)$. 交换$x$，$y$得反函数$y=\log_5(x-1)$，其定义域为$x>1$，故应选 C。
  2. 选择题 三角函数 · 解析几何 · 极坐标与参数方程
    极坐标方程$\rho \cos \theta = \frac\{4\}\{3\}$表示（ ）
    A.
    一条平行于$x$轴的直线
    B.
    一条垂直于$x$轴的直线
    C.
    一个圆
    D.
    一条抛物线
    显示答案
    答案:
    B
    解析:
    极坐标与直角坐标的关系为$x=\rho\cos\theta$，因此题给方程等价于$x=\frac\{4\}\{3\}$. 这是与$y$轴平行、因而垂直于$x$轴的一条直线，故应选 B。
  3. 选择题 待标注
    给出$20$个数：$87$，$91$，$94$，$88$，$93$，$91$，$89$，$87$，$92$，$86$，$90$，$92$，$88$，$90$，$91$，$86$，$89$，$92$，$95$，$88$，它们的和是（ ）
    A.

    B.
    $1799$
    C.
    $1879$
    D.
    $1899$
    显示答案
    答案:
    B
    解析:
    把这$20$个数分成前后两组，前十个数的和为$87+91+94+88+93+91+89+87+92+86=898$，后十个数的和为$90+92+88+90+91+86+89+92+95+88=901$. 因而总和为$898+901=1799$，故应选 B。
  4. 选择题 待标注
    在正方形$SG_1G_2G_3$中，$E$，$F$分别是$G_1G_2$及$G_2G_3$的中点，$D$是$EF$的中点. 现在沿$SE$，$SF$及$EF$把这个正方形折成一个四面体，使$G_1$，$G_2$，$G_3$三点重合，重合后的点记为$G$，那么，在四面体$S - EFG$中必有（ ）
    A.
    $SG \perp \triangle EFG$所在平面
    B.
    $SD \perp \triangle EFG$所在平面
    C.
    $GF \perp \triangle SEF$所在平面
    D.
    $GD \perp \triangle SEF$所在平面
    显示答案
    答案:
    A
    解析:
    设正方形边长为$\ell$. 折叠后$G_1$，$G_2$，$G_3$重合为$G$，所以$SG=SG_1=SG_3=\ell$，$GE=G_1E=\frac\{\ell\}\{2\}$，$GF=G_3F=\frac\{\ell\}\{2\}$. 在原正方形中，$SG_1\perp G_1E$，$SG_3\perp G_3F$，折叠保持相应三角形的边长和直角关系，故$SE^2=SG^2+GE^2$，$SF^2=SG^2+GF^2$. 由勾股定理的逆定理，$SG\perp GE$，$SG\perp GF$. 直线$GE$，$GF$在平面$EFG$内相交于$G$，因此$SG\perp$平面$EFG$，故应选 A。
  5. 选择题 三角函数
    当$x \in [-1,0]$时，在下面关系式中正确的是（ ）
    A.
    $\pi - \arccos (-x) = \arcsin \sqrt\{1 - x^2\}$
    B.
    $\pi - \arcsin (-x) = \arccos \sqrt\{1 - x^2\}$
    C.
    $\pi - \arccos x = \arcsin \sqrt\{1 - x^2\}$
    D.
    $\pi - \arcsin x = \arccos \sqrt\{1 - x^2\}$
    显示答案
    答案:
    C
    解析:
    令$\alpha=\arccos x$. 当$x\in[-1,0]$时，$\alpha\in[\frac\{\pi\}\{2\},\pi]$，并且$\sqrt\{1-x^2\}=\sqrt\{1-\cos^2\alpha\}=\sin\alpha$. 由于反正弦函数的值域为$[-\frac\{\pi\}\{2\},\frac\{\pi\}\{2\}]$，有$\arcsin\sqrt\{1-x^2\}=\arcsin(\sin\alpha)=\pi-\alpha=\pi-\arccos x$所以选项 C 对所有$x\in[-1,0]$成立. 再看其余选项：选项 A 左端为$\pi-\arccos(-x)$，而$-x\in[0,1]$，故该左端属于$[\frac\{\pi\}\{2\},\pi]$，右端属于$[0,\frac\{\pi\}\{2\}]$，只有在$x=0$时两端才可能相等； 选项 B 左端大于等于$\frac\{\pi\}\{2\}$，右端属于$[0,\frac\{\pi\}\{2\}]$，且取$x=0$时左端为$\pi$，右端为$\arccos 1=0$，不相等； 选项 D 取$x=0$时左端为$\pi$，右端为$0$. 因此只有 C 正确，故应选 C。
  6. 解答题 立体几何
    在$xOy$平面上，四边形$ABCD$的四个顶点坐标依次为$(0,0)$，$(1,0)$，$(2,1)$及$(0,3)$，求这个四边形绕$x$轴旋转一周所得到的几何体的体积。
    显示答案
    解析:
    由四边形边界可知，在$0\leq x\leq 1$时，截面中的纵坐标范围为$0\leq y\leq 3-x$； 在$1\leq x\leq 2$时，截面中的纵坐标范围为$x-1\leq y\leq 3-x$. 绕$x$轴旋转后，前一段所得截面为圆，后一段所得截面为圆环，因此$\begin\{gathered\} V=\pi\int_0^1(3-x)^2\mathrm\{d\}x+\pi\int_1^2\left((3-x)^2-(x-1)^2\right)\mathrm\{d\}x\\ =\pi\cdot\frac\{19\}\{3\}+\pi\int_1^2(8-4x)\mathrm\{d\}x =\frac\{19\pi\}\{3\}+2\pi=\frac\{25\pi\}\{3\}. \end\{gathered\}$
  7. 解答题 待标注
    求$\displaystyle\lim_\{n \to \infty\}\frac\{3^n + (-2)^n\}\{3^\{n + 1\} + (-2)^\{n + 1\}\}$。
    显示答案
    解析:
    令$r=-\frac\{2\}\{3\}$. 分子、分母同除以$3^n$，得$\frac\{3^n+(-2)^n\}\{3^\{n+1\}+(-2)^\{n+1\}\}=\frac\{1+r^n\}\{3-2r^n\}$因为$\lvert r\rvert=\frac\{2\}\{3\}<1$，所以$r^n\to0$，从而原极限为$\frac\{1\}\{3\}$。
  8. 解答题 三角函数
    已知$\sin \theta - \cos \theta = \frac\{1\}\{2\}$，求$\sin^3 \theta - \cos^3 \theta$的值。
    显示答案
    解析:
    令$s=\sin\theta$，$c=\cos\theta$. 由$s-c=\frac\{1\}\{2\}$及$s^2+c^2=1$，有$\frac\{1\}\{4\}=(s-c)^2=s^2+c^2-2sc=1-2sc$所以$sc=\frac\{3\}\{8\}$. 于是$s^3-c^3=(s-c)(s^2+sc+c^2)=\frac\{1\}\{2\}\left(1+\frac\{3\}\{8\}\right)=\frac\{11\}\{16\}$。
  9. 解答题 待标注
    如图，$AB$是圆$O$的直径，$PA$垂直于圆$O$所在的平面，$C$是圆周上不同于$A$，$B$的任一点. 求证：平面$PAC$垂直于平面$PBC$。
    显示答案
    解析:
    设圆$O$所在的平面为$\Pi$. 由$PA\perp\Pi$，过$C$作直线$l\parallel PA$，则$l\perp\Pi$，从而$l\perp BC$. 又因为$AB$是圆$O$的直径，且$C$是圆周上不同于$A$，$B$的点，由圆周角定理得$\angle ACB=90^\circ$，从而$AC\perp BC$. 直线$l$与$AC$相交于$C$，且$l$，$AC$都在平面$PAC$内，因此$BC\perp$平面$PAC$. 由于$BC$在平面$PBC$内，平面$PBC$与平面$PAC$垂直，即平面$PAC\perp$平面$PBC$。
  10. 解答题 三角函数 · 不等式
    当$\sin 2x > 0$时，求不等式$\log_\{0.5\}(x^2 - 2x - 15) > \log_\{0.5\}(x + 13)$的解集。
    显示答案
    解析:
    首先由对数真数为正，得$x^2-2x-15=(x-5)(x+3)>0$，$x+13>0$， 所以定义域为$(-13,-3)\cup(5,+\infty)$. 因为$0<0.5<1$，对数函数$\log_\{0.5\}x$在正数范围内是减函数，故原不等式等价于$x^2-2x-150$等价于$x\in\bigcup_\{k\in\Z\}\left(k\pi,k\pi+\frac\{\pi\}\{2\}\right)$. 将其与$(-4,-3)\cup(5,7)$相交，得解集为$(-\pi,-3)\cup(2\pi,7)$。

    显示答案
    解析:
    由于交换$A$，$B$不改变$\angle ACB$，不妨设$A=(0,a)$，$B=(0,b)$，其中$a>b>0$，并设$C=(x,0)$，其中$x>0$. 则 直线$CA$，$CB$的斜率分别为$-\frac\{a\}\{x\}$，$-\frac\{b\}\{x\}$. 因为$x^2+ab>0$，所以$\angle ACB$为锐角，且正切函数在$\left(0,\frac\{\pi\}\{2\}\right)$上严格递增，故只需使$\tan\angle ACB$最大。$\tan\angle ACB=\frac\{\frac\{a-b\}\{x\}\}\{1+\frac\{ab\}\{x^2\}\}=\frac\{x(a-b)\}\{x^2+ab\}=(a-b)\frac\{x\}\{x^2+ab\}$由均值不等式，$x+\frac\{ab\}\{x\}\geq2\sqrt\{ab\}$，所以$\frac\{x\}\{x^2+ab\}=\frac\{1\}\{x+ab/x\}\leq\frac\{1\}\{2\sqrt\{ab\}\}$. 等号当且仅当$x=\frac\{ab\}\{x\}$，即$x=\sqrt\{ab\}$. 因而当$C=(\sqrt\{ab\},0)$时，$\angle ACB$取得最大值。

    已知集合$A$和集合$B$各含有$12$个元素，$A \cup B$含有$4$个元素，试求同时满足下面两个条件的集合$C$的个数： ①$C \subseteq A \cup B$且$C$中含有$3$个元素； ②$C \cap A \neq \varnothing$（$\varnothing$表示空集）。
    显示答案
    解析:
    由$A\subseteq A\cup B$，必有$\lvert A\cup B\rvert\geq\lvert A\rvert=12$. 但原始试卷文件同时给出$\lvert A\cup B\rvert=4$，这与上述不等式矛盾. 因此，按原始试卷的并集题面，不存在满足已知条件的集合$A$，$B$，也就不存在满足所列两个条件的集合$C$； 字面解读只能得到“题设无解”，不能把它当作交集版本的数值答案。

    已知$x_1 > 0$，$x_1 \neq 1$，且$x_\{n+1\} = \frac\{x_n(x_n^2 + 3)\}\{3x_n^2 + 1\}$，（$n = 1$，$2$，$\cdots$）. 试证：数列$\\{x_n\\}$或者对任意自然数$n$都满足$x_n < x_\{n+1\}$，或者对任意自然数$n$都满足$x_n > x_\{n+1\}$。
    显示答案
    解析:
    记$f(x)=\frac\{x(x^2+3)\}\{3x^2+1\}$. 当$x>0$时，$f(x)>0$，且$f(x)-x=\frac\{2x(1-x^2)\}\{3x^2+1\}$，$f(x)-1=\frac\{(x-1)^3\}\{3x^2+1\}$. 若$00$，即$0x$. 由归纳法，当$01$，则$f(x)-1>0$且$f(x)-x<0$，即$f(x)>1$且$f(x)1$时，先由上述结论得$x_2=f(x_1)>1$且$x_21$，同样由上述结论得$x_\{n+1\}=f(x_n)>1$且$x_\{n+1\}1$以及$x_n>x_\{n+1\}$. 由于题设$x_1>0$且$x_1\neq1$，两种情形必有且仅有一种成立。

    求过点$(-1,0)$并与曲线$y = \frac\{x + 1\}\{x + 2\}$相切的直线方程。
    显示答案
    解析:
    设切点的横坐标为$t$，则切点为$T\left(t,\frac\{t+1\}\{t+2\}\right)$，其中$t\neq-2$. 曲线的导数为$y'=\frac\{(x+2)-(x+1)\}\{(x+2)^2\}=\frac\{1\}\{(x+2)^2\}$所以在$T$处的切线斜率为$\frac\{1\}\{(t+2)^2\}$. 由于切线过点$(-1,0)$，其方程也可写为$y=\frac\{x+1\}\{(t+2)^2\}$. 将切点坐标代入，得$\frac\{t+1\}\{t+2\}=\frac\{t+1\}\{(t+2)^2\}(t+1)$因而$(t+1)\bigl((t+2)-(t+1)\bigr)=0$，所以$t=-1$. 此时切线斜率为$1$，且经过$(-1,0)$，故所求直线方程为$y=x+1$。
