    答案:

    解析:

  11. 填空题 待标注
    如图，已知$AB$，$BC$是$\odot O$的两条弦，$AO \perp BC$，$AB = \sqrt{3}$，$BC = 2\sqrt{2}$，则$\odot O$的半径等于____。
    显示答案
    答案:
    $\frac{3}{2}$
    解析:
    设$M$为弦$BC$的中点. 因为圆心到弦的垂线平分弦，所以$AO\perp BC$使得$A$，$O$，$M$共线，且$BM=\frac{BC}{2}=\sqrt{2}$在直角三角形$ABM$中，$AM^2=AB^2-BM^2=3-2=1$所以$AM=1$. 设圆半径为$R$，$OM=u$. 在直角三角形$OMB$中，$R^2=u^2+2$，从而$R>u$. 若$O$在$A$、$M$之间，则$R+u=1$； 若三点不按此顺序排列，则$R-u=1$. 结合$R^2-u^2=2$分别得到$R-u=2$或$R+u=2$，两种情形均有$2R=3$. 因而$R=\frac{3}{2}$。
  12. 填空题 不等式
    若关于$x$的不等式$\left|ax - 2\right| < 3$的解集为$\left\{x\mid -\frac{5}{3} < x < \frac{1}{3}\right\}$，则$a =\underline{ }$。
    显示答案
    答案:
    $-3$
    解析:
    由绝对值不等式得$-3<ax-2<3$即$-1<ax<5$. 若$a=0$，则不等式恒成立，解集为$\R$，与题设不符. 若$a>0$，则解集为$\left(-\frac{1}{a},\frac{5}{a}\right)$，其左端点与右端点的绝对值之比为$1:5$，与题给解集不符. 因而$a<0$，除以$a$时不等号方向改变，解集为$\left(\frac{5}{a},-\frac{1}{a}\right)$. 比较端点得$\frac{5}{a}=-\frac{5}{3}$，所以$a=-3$，并且右端点也确为$-1/a=1/3$。
  13. 填空题 待标注
    若变量$x$，$y$满足约束条件$\begin{cases} y \leqslant x,\\ x + y \leqslant 4,\\ y \geqslant k, \end{cases}$且$z = 2x + y$的最小值为$-6$，则$k =$____。
    显示答案
    答案:
    $-2$
    解析:
    由$y\leqslant x$及目标函数中$x$的系数为正，对固定的$y$，使$z=2x+y$取得最小值时应取$x=y$. 于是$z\geqslant3y$. 约束还给出$y\geqslant k$，所以在可行域内$z\geqslant3y\geqslant3k$取$x=y=k$时，第三个约束和第一个约束均满足； 只要可行域存在，还需$2k\leqslant4$，本题所得$k$满足这一条件. 因而最小值为$3k$，由$3k=-6$得$k=-2$. 此时$(x,y)=(-2,-2)$可行，故结论成立。
  14. 填空题 解析几何
    如图，正方形$ABCD$和正方形$DEFG$的边长分别为$a$，$b$（$a < b$），原点$O$为$AD$的中点，抛物线$y^{2} = 2px$（$p > 0$） 经过$C$，$F$两点，则$\frac{b}{a} =$____。
    显示答案
    答案:
    $1+\sqrt{2}$
    解析:
    建立如图所示的直角坐标系，令$AD$在$x$轴上且正方形$ABCD$位于其下方，则$A\left(-\frac a2,0\right)$，$D\left(\frac a2,0\right)$，$C\left(\frac a2,-a\right)$，$F\left(\frac a2+b,b\right)$. 把点$C$代入抛物线方程，得$a^2=2p\cdot\frac a2=pa$，所以$p=a$. 再把点$F$代入，得$b^2=2a\left(\frac a2+b\right)=a^2+2ab$令$r=b/a$，由$a>0$得$r^2=1+2r$，即$r^2-2r-1=0$. 因为$b>a$，取正根，故$\frac ba=1+\sqrt2$。

    在平面直角坐标系中，$O$为原点，$A(-1,0)$，$B(0,\sqrt{3})$，$C(3,0)$，动点$D$满足$\left|\overrightarrow{CD}\right| = 1$，则$\left|\overrightarrow{OA} +\overrightarrow{OB} +\overrightarrow{OD}\right|$的最大值是____。

    答案:
    $1+\sqrt{7}$

  16. 解答题 概率统计
    某企业有甲，乙两个研发小组，他们研发新产品成功的概率分别为$\frac{2}{3}$和$\frac{3}{5}$，现安排甲组研发新产品$A$，乙组研发新产品$B$. 设甲，乙两组的研发相互独立. (1) 求至少有一种新产品研发成功的概率； (2) 若新产品$A$研发成功，预计企业可获利$120\text{ 万元}$；若新产品$B$研发成功，预计企业可获利$100\text{ 万元}$. 求该企业可获利的分布列和数学期望。
    显示答案
    解析:
    设事件$E$为甲组研发成功，事件$F$为乙组研发成功. 则$P(E)=\frac23$，$P(\overline E)=\frac13$，$P(F)=\frac35$，$P(\overline F)=\frac25$. 由于两组研发相互独立，至少有一种新产品成功的对立事件是两种产品都失败，所以$P(E\cup F)=1-P(\overline E\cap\overline F)=1-\frac13\cdot\frac25=\frac{13}{15}$设企业利润为随机变量$X$，单位为万元. 两种产品的成败组合互斥且完备，故$P(X=0)=P(\overline E\cap\overline F)=\frac{2}{15}$P(X=100)=P(\overline E\cap F)=\frac{3}{15}$，$P(X=120)=P(E\cap\overline F)=\frac{4}{15}$，$P(X=220)=P(E\cap F)=\frac{6}{15}$. 因此分布列为$\begin{array}{c|cccc}X&0&100&120&220\hlineP&\frac{2}{15}&\frac{3}{15}&\frac{4}{15}&\frac{6}{15}\end{array}$$数学期望为$E(X)=0\cdot\frac{2}{15}+100\cdot\frac{3}{15}+120\cdot\frac{4}{15}+220\cdot\frac{6}{15}=140$所以企业可获利的数学期望为$140 万元$。

  19. 解答题 数列
    已知数列$\{a_{n}\}$满足$a_1 = 1$，$|a_{n + 1} - a_n| = p^n$，$n \in \N^*$. (1) 若$\{a_n\}$是递增数列，且$a_1$，$2a_2$，$3a_3$成等差数列，求$p$的值； (2) 若$p = \frac{1}{2}$，且$\{a_{2n-1}\}$是递增数列，$\{a_{2n}\}$是递减数列，求数列$\{a_n\}$的通项公式。
    显示答案
    解析:
    因为$p^n=|a_{n+1}-a_n|\geqslant0$对任意正整数$n$成立，且第一问中的数列递增，所以$p>0$. 于是$a_2=1+p$，$a_3=1+p+p^2$. 三个数$a_1$，$2a_2$，$3a_3$成等差数列，故$4a_2=a_1+3a_3$代入上式得$4(1+p)=1+3(1+p+p^2)$，即$p(1-3p)=0$. 由$p>0$，得$p=\frac13$. 第二问中令$d_n=a_{n+1}-a_n$，则$|d_n|=2^{-n}$. 由奇数项组成的数列递增，$d_{2n-1}+d_{2n}=a_{2n+1}-a_{2n-1}>0$由于$|d_{2n-1}|=2|d_{2n}|$，只能有$d_{2n-1}=2^{-(2n-1)}$. 由偶数项组成的数列递减，$d_{2n}+d_{2n+1}=a_{2n+2}-a_{2n}<0$由于$|d_{2n}|=2|d_{2n+1}|$，只能有$d_{2n}=-2^{-2n}$. 因而对所有$n\geqslant1$，$d_n=\frac{(-1)^{n+1}}{2^n}$于是$a_n=1+\sum_{k=1}^{n-1}\frac{(-1)^{k+1}}{2^k} =1+\frac{1}{3}\left(1-\left(-\frac12\right)^{n-1}\right) =\frac43-\frac{(-1)^{n-1}}{3\cdot2^{n-1}}$
  20. 解答题 解析几何
    如图，$O$为坐标原点，椭圆$C_1: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$） 的左，右焦点分别为$F_1$，$F_2$，离心率为$e_1$；双曲线$C_2: \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$的左，右焦点分别为$F_3$，$F_4$，离心率为$e_2$. 已知$e_1 e_2 = \frac{\sqrt{3}}{2}$，且$|F_2 F_4| = \sqrt{3} - 1$. (1) 求$C_{1}$，$C_{2}$的方程； (2) 过$F_{1}$作$C_{1}$的不垂直于$y$轴的弦$AB$，$M$为弦$AB$的中点. 当直线$OM$与$C_{2}$交于$P$，$Q$两点时，求四边形$APBQ$面积的最小值。
    显示答案
    解析:
    设椭圆和双曲线的焦距参数分别为$c=\sqrt{a^2-b^2}$，$d=\sqrt{a^2+b^2}$. 则$e_1=c/a$，$e_2=d/a$，从而$e_1^2+e_2^2=\frac{c^2+d^2}{a^2}=2$，$e_1^2e_2^2=\frac34$. 所以$e_1^2$、$e_2^2$是方程$u^2-2u+\frac34=0$的两个根，即$\frac12$、$\frac32$. 由于椭圆离心率小于$1$，有$e_1=\frac{1}{\sqrt2}$，$e_2=\sqrt{\frac32}$. 又因为$F_2=(c,0)$，$F_4=(d,0)$，所以$a(e_2-e_1)=d-c=\sqrt3-1$而$e_2-e_1=\frac{\sqrt3-1}{\sqrt2}$，故$a=\sqrt2$. 于是$c=1$，$b^2=a^2-c^2=1$，即$C_1:\frac{x^2}{2}+y^2=1$，$C_2:\frac{x^2}{2}-y^2=1$. 第二问先设弦$AB$的斜率为$k$，由于题设排除了垂直于$y$轴的水平弦，故$k\ne0$. 直线方程为$y=k(x+1)$. 与椭圆联立得$(1+2k^2)x^2+4k^2x+2k^2-2=0$由根与系数的关系，弦中点为$M\left(-\frac{2k^2}{1+2k^2},\frac{k}{1+2k^2}\right)$因此直线$OM$的方向向量可取$(-2k,1)$. 令该直线上的点为$(x,y)=t(-2k,1)$，代入$C_2$得$(2k^2-1)t^2=1$由于题设要求有两个交点，必须有$k^2>\frac12$，此时$PQ=\frac{2\sqrt{4k^2+1}}{\sqrt{2k^2-1}}$设椭圆交点的横坐标之差的绝对值为$|\Delta x|$. 由上面二次方程的判别式，$|\Delta x|=\frac{2\sqrt{2(1+k^2)}}{1+2k^2}$所以$AB=|\Delta x|\sqrt{1+k^2}=\frac{2\sqrt2(1+k^2)}{1+2k^2}$四边形$APBQ$的两条对角线为$AB$、$PQ$，且交点为$M$. 因此用向量行列式计算面积，注意$\det\begin{pmatrix}1&k\\-2k&1\end{pmatrix}=1+2k^2$得到$S=\frac12|\Delta x|\cdot\frac{2}{\sqrt{2k^2-1}}(1+2k^2) =\frac{2\sqrt{2(1+k^2)}}{\sqrt{2k^2-1}}$有限斜率下$S^2=\frac{8(1+k^2)}{2k^2-1}=4+\frac{12}{2k^2-1}>4$还需考虑$AB\parallel y$轴的情形，此时弦为$x=-1$，其中点为$M=(-1,0)$，直线$OM$为$x$轴，与双曲线交于$(-\sqrt2,0)$、$(\sqrt2,0)$. 此时$AB=\sqrt2$，$PQ=2\sqrt2$，故$S=2$. 因而四边形$APBQ$面积的最小值为$2$。
  21. 解答题 函数 · 导数
    已知常数$a > 0$，函数$f(x) = \ln\left(1 + ax\right) - \frac{2x}{x + 2}$. (1) 讨论$f(x)$在区间$(0, +\infty)$上的单调性； (2) 若$f(x)$存在两个极值点$x_{1}$，$x_{2}$，且$f(x_{1}) + f(x_{2}) > 0$，求$a$的取值范围。
    显示答案
    解析:
    函数定义域为$\left(-\frac1a,+\infty\right)$，并且要排除$x=-2$（当该点属于上述区间时）. 在$(0,+\infty)$上，$f'(x)=\frac{a}{1+ax}-\frac{4}{(x+2)^2} =\frac{ax^2+4a-4}{(1+ax)(x+2)^2}$在所讨论区间内分母恒为正. 当$a\geqslant1$时，$ax^2+4a-4>0$，所以$f(x)$在$(0,+\infty)$上单调递增. 当$0<a<1$时，令分子为零，得$x_0=2\sqrt{\frac{1-a}{a}}$此时在$0<x<x_0$上有$f'(x)<0$，在$x>x_0$上有$f'(x)>0$，所以$f(x)$在$\left(0,2\sqrt{\frac{1-a}{a}}\right)$上单调递减，在$\left(2\sqrt{\frac{1-a}{a}},+\infty\right)$上单调递增. 若存在两个极值点，导数方程的两个根必须都在定义域内. 当$0<a<1$时令$t=2\sqrt{\frac{1-a}{a}}>0$导数的两个零点为$-t$、$t$. 当$a\ne\frac12$时，$t<\frac1a \quad\Longleftrightarrow\quad 4a(1-a)<1 \quad\Longleftrightarrow\quad (2a-1)^2>0$所以$-t>-\frac1a$，且$t\ne2$，故$\pm t$均在定义域内； 在定义域内除去可能的$x=-2$后，分母为正，故$f'(x)$的符号由$a(x^2-t^2)$决定，$-t$处由正变负、$t$处由负变正，二者确为极值点. 当$a=\frac12$时，$-t=-2$不在定义域内，只剩一个极值点. 因而存在两个极值点当且仅当$0<a<1$且$a\ne\frac12$. 计算函数值之和：$f(-t)+f(t)=\ln(1-a^2t^2)+\frac{4t^2}{4-t^2}$由$t^2=4(1-a)/a$，可化为$f(-t)+f(t)=2\ln|2a-1|+\frac{4(1-a)}{2a-1}$当$\frac12<a<1$时，令$u=2a-1\in(0,1)$，上式为$2\left(\ln u+\frac1u-1\right)$函数$\ln u+1/u-1$在$(0,1)$上为正，因为其在$u=1$的值为零，且导数$(u-1)/u^2<0$. 因而此时函数值之和大于零. 当$0<a<\frac12$时，令$u=1-2a\in(0,1)$，上式为$2\ln u-\frac2u-2<0$所以满足条件的参数范围为$a\in\left(\frac12,1\right)$。
