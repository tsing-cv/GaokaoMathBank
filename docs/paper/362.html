  13. 填空题 待标注
    记$\left(2x + \frac{1}{x}\right)^{n}$的展开式中第$m$项的系数为$b_{m}$，若$b_{3} = 2b_{4}$，则$n =$____。
    显示答案
    答案:
    5
    解析:
    展开式的第$r+1$项为$\mathrm C_n^r(2x)^{n-r}\left(\frac1x\right)^r =\mathrm C_n^r2^{n-r}x^{n-2r}$因此$b_3=\mathrm C_n^2 2^{n-2}$，$b_4=\mathrm C_n^3 2^{n-3}$. 由$b_3=2b_4$得$\mathrm C_n^2 2^{n-2}=2\mathrm C_n^3 2^{n-3} \iff \mathrm C_n^2=\mathrm C_n^3$于是$\frac{n(n-1)}2=\frac{n(n-1)(n-2)}6$从而$n-2=3$，即$n=5$。
  14. 填空题 待标注
    将圆$x^{2} + y^{2} = 1$沿$x$轴正向平移$1$个单位后所得到圆$C$，则圆$C$的方程是____；若过点$(3,0)$的直线$l$和圆$C$相切，则直线$l$的斜率为____。
    显示答案
    答案:
    $(x-1)^2+y^2=1$；$\pm\frac{\sqrt{3}}{3}$
    解析:
    圆沿$x$轴正向平移$1$个单位后，圆心由$(0,0)$变为$(1,0)$，半径不变，所以圆$C$的方程为$(x-1)^2+y^2=1$. 过$(3,0)$的竖直直线为$x=3$，圆心到它的距离为$2$，不是切线. 因此其余切线均可设为$y=k(x-3)$，即$kx-y-3k=0$. 直线与圆相切，当且仅当圆心到直线的距离等于半径：$\frac{|k-3k|}{\sqrt{k^2+1}}=1 \iff \frac{2|k|}{\sqrt{k^2+1}}=1 \iff k^2=\frac13$故$k=\pm\frac{\sqrt3}{3}$。
  15. 填空题 函数
    设$[x]$表示不超$x$的最大整数（如$[2] = 2$，$\left[\frac{5}{4}\right] = 1$）. 对于给定的$n \in \mathbf{N}^*$，定义$\mathrm C_n^x = \frac{n(n - 1) \cdots (n - [x] + 1)}{x(x - 1) \cdots (x - [x] + 1)}$，$x \in [1, +\infty)$，则$\mathrm C_8^{\frac{3}{2}} =$____；当$x \in [2, 3)$时，函数$\mathrm C_8^x$的值域是____。
    显示答案
    答案:
    $\frac{16}{3}$；$\left(\frac{28}{3},28\right]$
    解析:
    当$x=\frac32$时，$[x]=1$，所以$\mathrm C_8^{\frac32}=\frac8{\frac32}=\frac{16}{3}$当$x\in[2,3)$时，$[x]=2$，于是$\mathrm C_8^x=\frac{8\times7}{x(x-1)}=\frac{56}{x(x-1)}$函数$x(x-1)$在$[2,3)$上递增，取值范围为$[2,6)$，因此$\mathrm C_8^x\in\left(\frac{56}{6},\frac{56}{2}\right] =\left(\frac{28}{3},28\right]$
  16. 解答题 概率统计
    甲，乙，丙三人参加了一家公司的招聘面试，面试合格者可正式签约. 甲表示只要面试合格就签约. 乙，丙则约定：两人面试都合格就一同签约. 否则两人都不签约. 设每人面试合格的概率都是$\frac{1}{2}$，且面试是否合格互不影响. 求： (1) 至少有$1$人面试合格的概率； (2) 没有人签约的概率。
    显示答案
    解析:
    (1) 三人均未面试合格的概率为$\left(\frac{1}{2}\right)^3=\frac{1}{8}$，所以至少有$1$人面试合格的概率为$1-\frac{1}{8}=\frac{7}{8}$. (2) 没有人签约时，甲必须面试不合格，且乙、丙不能同时面试合格. 由相互独立性，所求概率为$\frac{1}{2}\left[1-\left(\frac{1}{2}\right)^2\right]=\frac{3}{8}$。
  17. 解答题 函数 · 三角函数
    已知函数$f(x) = \cos^2 \frac{x}{2} - \sin^2 \frac{x}{2} + \sin x$. (1) 求函数$f(x)$的最小正周期； (2) 当$x_0 \in \left(0, \frac{\pi}{4}\right)$且$f(x_0) = \frac{4\sqrt{2}}{5}$时，求$f\left(x_0 + \frac{\pi}{6}\right)$的值。
    显示答案
    解析:
    (1) 由$\cos^2\frac{x}{2}-\sin^2\frac{x}{2}=\cos x$，得$f(x)=\cos x+\sin x=\sqrt{2}\sin\left(x+\frac{\pi}{4}\right)$，所以$f(x)$的最小正周期为$2\pi$. (2) 由已知条件，$\cos x_0+\sin x_0=\frac{4\sqrt{2}}{5}$. 于是$\sin 2x_0=\left(\cos x_0+\sin x_0\right)^2-1=\frac{7}{25}$. 因为$0<2x_0<\frac{\pi}{2}$，所以$\cos 2x_0=\frac{24}{25}$，从而$\cos x_0-\sin x_0>0$. 又$\left(\cos x_0-\sin x_0\right)^2=1-\sin 2x_0=\frac{18}{25}$，故$\cos x_0-\sin x_0=\frac{3\sqrt{2}}{5}$. 因此$\cos x_0=\frac{7\sqrt{2}}{10}$，$\sin x_0=\frac{\sqrt{2}}{10}$，所以$f\left(x_0+\frac{\pi}{6}\right)=\cos\left(x_0+\frac{\pi}{6}\right)+\sin\left(x_0+\frac{\pi}{6}\right)$$f\left(x_0+\frac{\pi}{6}\right)=\frac{\sqrt{3}}{2}\left(\cos x_0+\sin x_0\right)+\frac{1}{2}\left(\cos x_0-\sin x_0\right)=\frac{4\sqrt{6}+3\sqrt{2}}{10}$
  18. 解答题 立体几何
    如图所示，四棱锥$P-ABCD$的底面$ABCD$是边长为$1$的菱形，$\angle BCD = 60^\circ$，$E$是$CD$的中点，$PA \perp$底面$ABCD$，$PA = \sqrt{3}$. (1) 证明：平面$PBE \perp$平面$PAB$； (2) 求二面角$A - BE - P$的大小。
    显示答案
    解析:
    建立如下一组空间直角坐标系，令$A\left(0,0,0\right)$，$B\left(1,0,0\right)$，$D\left(\frac{1}{2},\frac{\sqrt{3}}{2},0\right)$，则$C\left(\frac{3}{2},\frac{\sqrt{3}}{2},0\right)$. 由$E$是$CD$的中点以及$PA\perp$底面、$PA=\sqrt{3}$，可取$E\left(1,\frac{\sqrt{3}}{2},0\right)$，$P\left(0,0,\sqrt{3}\right)$. (1) 在平面$PAB$内，$\overrightarrow{AB}=\left(1,0,0\right)$，$\overrightarrow{AP}=\left(0,0,\sqrt{3}\right)$，且$\overrightarrow{BE}=\left(0,\frac{\sqrt{3}}{2},0\right)$. 因为$\overrightarrow{BE}\cdot\overrightarrow{AB}=0$，$\overrightarrow{BE}\cdot\overrightarrow{AP}=0$，所以$BE\perp$平面$PAB$. 又因为$BE\subset$平面$PBE$，所以平面$PBE\perp$平面$PAB$. (2) 平面$ABE$就是底面所在平面. 过棱$BE$上的点$B$，在平面$ABE$内作$BA$，在平面$PBE$内作$BP$. 由$\overrightarrow{BA}=\left(-1,0,0\right)$，$\overrightarrow{BP}=\left(-1,0,\sqrt{3}\right)$，得$\overrightarrow{BA}\cdot\overrightarrow{BE}=0$，$\overrightarrow{BP}\cdot\overrightarrow{BE}=0$，所以二面角$A-BE-P$的平面角为$\angle ABP$. 又$|BA|=1$，$|BP|=2$，且$\overrightarrow{BA}\cdot\overrightarrow{BP}=1$，故$\cos\angle ABP=\frac{1}{1\cdot2}=\frac{1}{2}$. 因此二面角$A-BE-P$的大小为$\frac{\pi}{3}=60^\circ$。
  19. 解答题 解析几何
    已知椭圆的中心在原点，一个焦点是$F(2,0)$，且两条准线间的距离为$\lambda$（$\lambda > 4$）. (1) 求椭圆的方程； (2) 若存在过点$A(1,0)$的直线$l$，使点$F$关于直线$l$的对称点在椭圆上，求$\lambda$的取值范围。
    显示答案
    解析:
    设椭圆的长半轴为$a$，短半轴为$b$，半焦距为$c$，离心率为$e$. 因为焦点为$F(2,0)$，所以$c=2$，且$a^2-b^2=c^2=4$. 椭圆的两条准线分别为$x=\frac{a}{e}$和$x=-\frac{a}{e}$，故$\lambda=\frac{2a}{e}=\frac{2a^2}{c}=a^2$. 从而$a^2=\lambda$，$b^2=\lambda-4$. (1) 椭圆的方程为$\frac{x^2}{\lambda}+\frac{y^2}{\lambda-4}=1$(2) 设点$F$关于直线$l$的对称点为$F'$. 因为直线$l$经过$A$，反射保持点到$A$的距离不变，所以$AF'=AF=1$，即$F'$在圆$\left(x-1\right)^2+y^2=1$上. 反过来，圆上任一点都可以取$AF$与$AF'$的角平分线作为反射轴（当$F'=F$时取直线$AF$），因此题设条件等价于该圆与椭圆有公共点. 由圆的方程得$y^2=2x-x^2$，且$0\leqslant x\leqslant2$. 代入椭圆方程，得$\frac{x^2}{\lambda}+\frac{2x-x^2}{\lambda-4}=1$即$4x^2-2\lambda x+\lambda\left(\lambda-4\right)=0$. 该方程有实根的充要条件是$\Delta=4\lambda\left(16-3\lambda\right)\geqslant0$结合$\lambda>4$，可得$4<\lambda\leqslant\frac{16}{3}$. 还需验证此范围内的根确实给出圆上的点. 当$4<\lambda\leqslant\frac{16}{3}$时，方程的根为$x=\frac{\lambda\pm\sqrt{\lambda\left(16-3\lambda\right)}}{4}$. 由$\lambda>4$可知较小的根大于$0$，而$\lambda\left(16-3\lambda\right)\leqslant\left(8-\lambda\right)^2$，所以较大的根不超过$2$. 因而至少有一个根属于$[0,2]$，此时$y^2=x\left(2-x\right)\geqslant0$，公共点确实存在。
  20. 解答题 三角函数 · 数列
    数列$\{a_{n}\}$满足$a_1 = 1$，$a_2 = 2$，$a_{n+2} = \left(1 + \cos^2\frac{n\pi}{2}\right)a_n + \sin^2\frac{n\pi}{2}$，$\ n = 1$，$2$，$3$，$\dots$. (1) 求$a_{3}$，$a_{4}$，并求数列$\{a_{n}\}$的通项公式； (2) 设$S_{k} = a_{1} + a_{3} + \dots + a_{2k-1}$，$T_{k} = a_{2} + a_{4} + \dots + a_{2k}$，$W_{k} = \frac{2S_{k}}{2 + T_{k}}$（$k \in \mathbf{N}^{*}$），求使$W_{k} > 1$的所有$k$的值，并说明理由。
    显示答案
    解析:
    当$n$为奇数时，$\cos^2\frac{n\pi}{2}=0$，$\sin^2\frac{n\pi}{2}=1$，递推式化为$a_{n+2}=a_n+1$. 当$n$为偶数时，$\cos^2\frac{n\pi}{2}=1$，$\sin^2\frac{n\pi}{2}=0$，递推式化为$a_{n+2}=2a_n$. (1) 由上述两个递推关系，$a_3=a_1+1=2$，$a_4=2a_2=4$. 对任意正整数$r$，分别沿奇数项和偶数项递推，得$a_{2r-1}=r$，$a_{2r}=2^r$. 因此数列的通项公式为$a_n= \begin{cases} \dfrac{n+1}{2},&n\text{为奇数},\\ 2^{\frac{n}{2}},&n\text{为偶数}. \end{cases}$(2) 由奇数项和偶数项的通项公式，$S_k=1+2+\cdots+k=\frac{k\left(k+1\right)}{2}$，$T_k=2+2^2+\cdots+2^k=2^{k+1}-2$. 所以$W_k=\frac{k\left(k+1\right)}{2^{k+1}}$. 当$k=1$时，$2^{k+1}=4>2=k\left(k+1\right)$； 当$k=2$时，$2^{k+1}=8>6=k\left(k+1\right)$. 若对某个$k\geqslant2$有$2^{k+1}>k\left(k+1\right)$，则$2^{k+2}>2k\left(k+1\right)\geqslant\left(k+1\right)\left(k+2\right)$，其中最后一个不等式等价于$k\geqslant2$. 由归纳法，任意正整数$k$都有$2^{k+1}>k\left(k+1\right)$，故$W_k<1$. 因此不存在使$W_k>1$的正整数$k$。
  21. 解答题 函数 · 导数
    已知函数$f(x) = \frac{1}{4} x^4 + x^3 - \frac{9}{2} x^2 + cx$有三个极值点. (1) 证明：$-27 < c < 5;$(2) 若存在实数$c$，使函数$f(x)$在区间$[a, a + 2]$上单调递减，求$a$的取值范围。
    显示答案
    解析:
    记$g(x)=f'(x)=x^3+3x^2-9x+c$，则$g'(x)=3\left(x+3\right)\left(x-1\right)$. 因此$g(x)$在$(-\infty,-3)$和$(1,+\infty)$上递增，在$(-3,1)$上递减，$x=-3$是极大值点，$x=1$是极小值点. (1) 因为$g(x)$是首项系数为正的三次函数，要有三个互不相同的实根，充要条件是极大值大于$0$且极小值小于$0$. 计算得$g(-3)=c+27$，$g(1)=c-5$. 所以$c+27>0$，$c-5<0$，即$-27<c<5$. (2) 由第（1）问，所取的$c$必须满足$-27<c<5$. 令$h(x)=x^3+3x^2-9x$，则$g(x)=h(x)+c$. 因为$h(x)-27=x^3+3x^2-9x-27=\left(x-3\right)\left(x+3\right)^2$，所以$h(x)<27$当且仅当$x<3$且$x\neq-3$. 若$f(x)$在$[a,a+2]$上单调递减，则区间内应有$g(x)\leqslant0$. 由于$c>-27$，有$g(-3)=c+27>0$，并且当$x\geqslant3$时$h(x)\geqslant27$，从而$g(x)>0$. 因此区间$[a,a+2]$既不能包含$-3$，又必须满足$a+2<3$. 这给出$a<-5$或$-3<a<1$. 反之，若$a<-5$或$-3<a<1$，则$[a,a+2]\subset(-\infty,3)$且不含$-3$，从而在该区间上$h(x)<27$. 令$M=\max_{x\in[a,a+2]}h(x)$，则$M<27$，所以可以取$-27<c<\min\left\{5,-M\right\}$. 此时$c$满足第（1）问的条件，且对区间内任意$x$有$f'(x)=h(x)+c\leqslant M+c<0$，故$f(x)$在$[a,a+2]$上单调递减. 综上，$a$的取值范围为$\left(-\infty,-5\right)\cup\left(-3,1\right)$。
