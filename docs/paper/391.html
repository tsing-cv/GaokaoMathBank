2009年安徽卷（理）

2009年 · 安徽 · 理科 · 真题 · 共 19 题

  1. 选择题 复数
    $i$是虚数单位，若$\frac{1 + 7i}{2 - i} = a + bi$（$a$，$b\in\R$），则乘积$ab$的值是（ ）
    A.
    $-15$
    B.
    $-3$
    C.
    $3$
    D.
    $15$
    显示答案
    答案:
    B
    解析:
    将分子、分母同乘以分母的共轭复数，得$\frac{1+7i}{2-i}=\frac{(1+7i)(2+i)}{(2-i)(2+i)}=\frac{-5+15i}{5}=-1+3i$由复数相等的充要条件，$a=-1$，$b=3$，所以$ab=-3$，故选 B。
  2. 选择题 集合与逻辑
    若集合$A = \{x \mid |2x - 1| < 3\}$，$B = \left\{x \mid \frac{2x + 1}{3 - x} < 0\right\}$，则$A \cap B$是（ ）
    A.
    $\left\{x\mid -1 < x < -\frac{1}{2}\text{或} 2 < x < 3\right\}$
    B.
    $\{x\mid 2 < x < 3\}$
    C.
    $\left\{x\mid -\frac{1}{2} < x < 2\right\}$
    D.
    $\left\{x\mid -1 < x < -\frac{1}{2}\right\}$
    显示答案
    答案:
    D
    解析:
    由$|2x-1|<3$，得$-3<2x-1<3$所以$-1<x<2$. 对于集合$B$，分式小于零时分子、分母异号，故$\frac{2x+1}{3-x}<0 \Longleftrightarrow x<-\frac{1}{2}\ \text{或}\ x>3$因此$A\cap B=(-1,2)\cap\left[\left(-\infty,-\frac{1}{2}\right)\cup(3,+\infty)\right] =\left(-1,-\frac{1}{2}\right)$故选 D。
  3. 选择题 函数
    下列选项中，$p$是$q$的必要不充分条件的是（ ）
    A.
    $p: a + c > b + d$，$q: a > b$且$c > d$
    B.
    $p: a > 1$，$b > 1$，$q: f(x) = a^x - b$（$a > 0$，且$a \neq 1$）的图象不过第二象限
    C.
    $p: x = 1$，$q: x^2 = x$
    D.
    $p: a > 1$，$q: f(x) = \log_a x$（$a > 0$，且$a \neq 1$）在$(0, +\infty)$上为增函数
    显示答案
    答案:
    A
    解析:
    “$p$是$q$的必要条件”要求$q\Rightarrow p$； “不充分”还要求$p\not\Rightarrow q$. 选项 A 中，若$q$成立，则$a+c>b+d$所以$q\Rightarrow p$. 但取$a=2$，$b=1$，$c=0$，$d=0$，有$p$成立而$c>d$不成立，故$p\not\Rightarrow q$. 选项 B 中，$a>1$，$b>1$能推出图象不过第二象限，但取$a>1$，$b=1$时图象仍不过第二象限，故$p$不是必要条件. 选项 C 中，$x=1$能推出$x^2=x$，但$x=0$也满足$x^2=x$，故$p$是充分不必要条件. 选项 D 中，对数函数在$(0,+\infty)$上递增当且仅当$a>1$，是充要条件. 因此只有选项 A 符合，故选 A。
  4. 选择题 数列
    已知$\{a_n\}$为等差数列，$a_1 + a_3 + a_5 = 105$，$a_2 + a_4 + a_6 = 99$. 以$S_n$表示$\{a_n\}$的前$n$项和，则使得$S_n$达到最大值的$n$是（ ）
    A.
    $21$
    B.
    $20$
    C.
    $19$
    D.
    $18$
    显示答案
    答案:
    B
    解析:
    设等差数列的公差为$d$. 由题意，$a_1+a_3+a_5=3(a_1+2d)=105$即$a_1+2d=35$； 同理$a_2+a_4+a_6=3(a_1+3d)=99$即$a_1+3d=33$. 两式相减得$d=-2$，再得$a_1=39$. 于是$S_n=\frac{n}{2}\left[2a_1+(n-1)d\right]=n(40-n)=400-(n-20)^2$由于$n$为正整数，$S_n$在$n=20$时取得最大值，故选 B。
  5. 选择题 不等式
    若不等式组$\begin{cases} x \geqslant 0,\\ x + 3y \geqslant 4,\\ 3x + y \leqslant 4 \end{cases}$所表示的平面区域被直线$y = kx + \frac{4}{3}$分为面积相等的两部分，则$k$的值是（ ）
    A.
    $\frac{7}{3}$
    B.
    $\frac{3}{7}$
    C.
    $\frac{4}{3}$
    D.
    $\frac{3}{4}$
    显示答案
    答案:
    A
    解析:
    三条边界直线$x=0$、$x+3y=4$、$3x+y=4$围成三角形. 由$x=0$，$x+3y=4$得顶点$\left(0,\frac{4}{3}\right)$； 由$x=0$，$3x+y=4$得顶点$(0,4)$； 联立另外两条直线得顶点$(1,1)$. 直线$y=kx+\frac{4}{3}$经过顶点$\left(0,\frac{4}{3}\right)$. 从一个顶点出发的直线把三角形分成相等的两部分，当且仅当它经过对边的中点. 对边端点为$(0,4)$、$(1,1)$，其中点为$M=\left(\frac{1}{2},\frac{5}{2}\right)$故$k=\frac{\frac{5}{2}-\frac{4}{3}}{\frac{1}{2}}=\frac{7}{3}$故选 A。
  6. 选择题 函数 · 三角函数
    已知函数$f(x) = \sqrt{3}\sin \omega x + \cos \omega x$（$\omega > 0$），$y = f(x)$的图象与直线$y = 2$的两个相邻交点的距离等于$\pi$，则$f(x)$的单调递增区间是（ ）
    A.
    $\left[k\pi - \frac{\pi}{12}, k\pi + \frac{5\pi}{12}\right],\ k\in \Z$
    B.
    $\left[k\pi + \frac{5\pi}{12}, k\pi + \frac{11\pi}{12}\right]$，$\ k\in \Z$
    C.
    $\left[k\pi - \frac{\pi}{3}, k\pi + \frac{\pi}{6}\right]$，$\ k\in \Z$
    D.
    $\left[k\pi + \frac{\pi}{6}, k\pi + \frac{2\pi}{3}\right]$，$\ k\in \Z$
    显示答案
    答案:
    C
    解析:
    将函数化为$f(x)=2\sin\left(\omega x+\frac{\pi}{6}\right)$图象与$y=2$相交时，必须有$\sin\left(\omega x+\frac{\pi}{6}\right)=1$即$\omega x+\frac{\pi}{6}=\frac{\pi}{2}+2k\pi$，其中$k\in\Z$. 相邻交点的纵坐标相同，故其距离等于横坐标之差$\frac{2\pi}{\omega}$，由题意$\frac{2\pi}{\omega}=\pi$所以$\omega=2$. 此时$f'(x)=4\cos\left(2x+\frac{\pi}{6}\right)$当$-\frac{\pi}{2}+2k\pi\leqslant 2x+\frac{\pi}{6}\leqslant\frac{\pi}{2}+2k\pi$时，$f'(x)\geqslant0$，化得$-\frac{\pi}{3}+k\pi\leqslant x\leqslant\frac{\pi}{6}+k\pi$因此单调递增区间为$\left[k\pi-\frac{\pi}{3},k\pi+\frac{\pi}{6}\right]$，故选 C。
  7. 选择题 函数 · 导数
    已知函数$f(x)$在$\R$上满足$f(x) = 2f(2 - x) - x^2 + 8x - 8$，则曲线$y = f(x)$在点$(1, f(1))$处的切线方程是（ ）
    A.
    $y = 2x - 1$
    B.
    $y = x$
    C.
    $y = 3x - 2$
    D.
    $y = -2x + 3$
    显示答案
    答案:
    A
    解析:
    题目所述切线存在，故先由已知关系式求出函数值，再用差商求切线斜率. 令$x=1$，得$f(1)=2f(1)-1+8-8$所以$f(1)=1$. 设切线斜率为$f'(1)$. 在已知关系式中令$x=1+h$，再减去$f(1)=1$，得$f(1+h)-f(1)=2\bigl[f(1-h)-f(1)\bigr]+6h-h^2$当$h\ne0$时两边除以$h$，令$h\to0$，利用$\frac{f(1-h)-f(1)}{h}=-\frac{f(1-h)-f(1)}{-h}\longrightarrow-f'(1)$得到$f'(1)=-2f'(1)+6$，所以$f'(1)=2$. 因而切线方程为$y-f(1)=f'(1)(x-1)$即$y-1=2(x-1)$，所以$y=2x-1$，故选 A。
  8. 选择题 立体几何 · 概率统计
    考察正方体 6 个面的中心，甲从这 6 个点中任意选两个点连成直线，乙也从这 6 个点中任意选两个点连成直线，则所得的两条直线相互平行但不重合的概率等于（ ）
    A.
    $\frac{1}{75}$
    B.
    $\frac{2}{75}$
    C.
    $\frac{3}{75}$
    D.
    $\frac{4}{75}$
    显示答案
    答案:
    D
    解析:
    把正方体边长按比例取为$2$，则六个面中心可表示为$(\pm1,0,0)$，$(0,\pm1,0)$，$(0,0,\pm1)$. 甲、乙各从六点中选两个点，可能的直线各有$\mathrm C_6^2=15$条，故总数为$15^2=225$. 连接同一坐标轴上的两个相对面中心所得的直线共有$3$条，它们方向各不相同. 对于任意两个不同坐标轴，例如$x$轴和$y$轴，四个相应的线段分成两组，每组两条平行且不重合的直线； 三组选轴共得到$6$组这样的平行线. 因而有利的有序选法数为$6\times2=12$. 所以所求概率为$\frac{12}{225}=\frac{4}{75}$故选 D。
  9. 填空题 待标注
    若随机变量$X \sim N(\mu, \sigma^2)$，则$P(X \leqslant \mu) =$____。
    显示答案
    答案:
    $\frac{1}{2}$
    解析:
    正态分布$N(\mu,\sigma^2)$的密度曲线关于直线$x=\mu$对称，且$P(X=\mu)=0$. 因此对称的两侧概率相等，满足$P(X\leqslant\mu)=P(X\geqslant\mu)=\frac{1}{2}$
  10. 填空题 三角函数 · 极坐标与参数方程
    以直角坐标系的原点为极点，$x$轴的正半轴为极轴，并在两种坐标系中取相同的长度单位. 已知直线的极坐标方程为$\theta = \frac{\pi}{4}$（$\rho \in \R$），它与曲线$\begin{cases} x = 1 + 2\cos \alpha,\\ y = 2 + 2\sin \alpha, \end{cases}$（$\alpha$为参数）相交于两点$A$和$B$，则$|AB| =$____。
    显示答案
    答案:
    $\sqrt{14}$
    解析:
    极坐标方程$\theta=\frac{\pi}{4}$且$\rho\in\R$表示直线$y=x$. 参数方程表示的曲线是圆$(x-1)^2+(y-2)^2=4$代入$y=x$，得$(x-1)^2+(x-2)^2=4 \Longleftrightarrow 2x^2-6x+1=0$两交点的横坐标为$x_1=\frac{3-\sqrt{7}}{2}$，$x_2=\frac{3+\sqrt{7}}{2}$. 由于两点均在$y=x$上，$|AB|=\sqrt{(x_2-x_1)^2+(x_2-x_1)^2}=\sqrt{2}(x_2-x_1)=\sqrt{14}$

  12. 填空题 向量
    给定两个长度为 1 的平面向量$\overrightarrow{OA}$和$\overrightarrow{OB}$，它们的夹角为$120^{\circ}$. 如图所示，点$C$在以$O$为圆心的圆弧$\overset{\frown}{AB}$上变动. 若$\overrightarrow{OC} = x\overrightarrow{OA} + y\overrightarrow{OB}$，其中$x$，$y\in\R$，则$x + y$的最大值是____。
    显示答案
    答案:
    2
    解析:
    记$\mathbf{u}=\overrightarrow{OA}$，$\mathbf{v}=\overrightarrow{OB}$，$\mathbf{w}=\overrightarrow{OC}$. 则$|\mathbf{u}|=|\mathbf{v}|=|\mathbf{w}|=1$，$\mathbf{u}\cdot\mathbf{v}=\cos120^{\circ}=-\frac{1}{2}$. 由$\mathbf{w}=x\mathbf{u}+y\mathbf{v}$，两边与$\mathbf{u}+\mathbf{v}$作数量积，得$\mathbf{w}\cdot(\mathbf{u}+\mathbf{v})=\frac{x+y}{2}$又$|\mathbf{u}+\mathbf{v}|^2=1+1+2\cos120^{\circ}=1$所以由数量积不等式$x+y=2\mathbf{w}\cdot(\mathbf{u}+\mathbf{v})\leqslant2|\mathbf{w}|\,|\mathbf{u}+\mathbf{v}|=2$当$\mathbf{w}$与$\mathbf{u}+\mathbf{v}$同向时取等号； 该方向位于圆弧$\overset{\frown}{AB}$上. 因而$x+y$的最大值为$2$。
  13. 填空题 集合与逻辑
    对于四面体$ABCD$，下列命题正确的是____.（写出所有正确命题的编号） ① 相对棱$AB$与$CD$所在的直线异面； ② 由顶点$A$作四面体的高，其垂足是$\triangle BCD$的三条高线的交点； ③ 若分别作$\triangle ABC$和$\triangle ABD$的边$AB$上的高，则这两条高所在直线异面； ④ 分别作三组相对棱中点的连线，所得的三条线段相交于一点； ⑤ 最长棱必有某个端点，由它引出的另两条棱的长度之和大于最长棱。
    显示答案
    答案:
    $(1)(4)(5)$
    解析:
    {(1)} 若直线$AB$与$CD$共面，则四个顶点$A$，$B$，$C$，$D$共面，与四面体非退化矛盾，所以相对棱所在的直线异面，命题{(1)}正确. {(2)} 从$A$向平面$BCD$作垂线所得垂足，只由点$A$的位置决定； 它不必是三角形$BCD$的三条高线交点. 例如取$B(0,0,0)$，$C(2,0,0)$，$D(1,1,0)$，$A(0,0,1)$，则高的垂足为$B$，而$B$不是三角形$BCD$的垂心，命题{(2)}错误. {(3)} 在正四面体中，设$M$为$AB$的中点，则三角形$ABC$和三角形$ABD$在边$AB$上的高都经过$M$，两条高所在直线相交而非异面，命题{(3)}错误. {(4)} 设$M_{AB}$、$M_{CD}$分别为$AB$、$CD$的中点，则线段$M_{AB}M_{CD}$的中点的位置向量为$\frac{1}{2}\left(\frac{\overrightarrow{OA}+\overrightarrow{OB}}{2}+\frac{\overrightarrow{OC}+\overrightarrow{OD}}{2}\right)=\frac{\overrightarrow{OA}+\overrightarrow{OB}+\overrightarrow{OC}+\overrightarrow{OD}}{4}$对另外两组相对棱也得到同一个点，所以三条线段相交于一点，命题{(4)}正确. {(5)} 设最长棱为$CD$. 三角形$ACD$和$BCD$的三角不等式分别给出$AC+AD>CD$，$BC+BD>CD$. 若同时有$AC+BC\leqslant CD$和$AD+BD\leqslant CD$，两式相加将得到$AC+AD+BC+BD\leqslant2CD$这与前面的两个不等式相加所得的严格不等式矛盾. 因而$AC+BC>CD$或$AD+BD>CD$，即最长棱的某个端点所引出的另两条棱之和大于最长棱，命题{(5)}正确. 所以正确命题的编号为$(1)(4)(5)$。
  14. 解答题 三角函数
    在$\triangle ABC$中，$\sin (C - A) = 1$，$\sin B = \frac{1}{3}$. (1) 求$\sin A$的值； (2) 设$AC = \sqrt{6}$，求$\triangle ABC$的面积。
    显示答案
    解析:
    (1) 因为$A$，$B$，$C$是三角形的内角，所以$C-A\in(-\pi,\pi)$. 由$\sin(C-A)=1$，得$C-A=\frac{\pi}{2}$，即$C=A+\frac{\pi}{2}$. 从而$B=\pi-A-C=\frac{\pi}{2}-2A$，且$0<A<\frac{\pi}{4}$. 因此$\frac{1}{3}=\sin B=\sin\left(\frac{\pi}{2}-2A\right)=\cos 2A$于是$\sin^{2}A=\frac{1-\cos 2A}{2}=\frac{1}{3}$因为$A$是三角形内角，$\sin A>0$，所以$\sin A=\frac{\sqrt{3}}{3}$. (2) 设$b=AC=\sqrt{6}$，$c=AB$. 由正弦定理，$\frac{c}{\sin C}=\frac{b}{\sin B}$又$\sin C=\sin\left(A+\frac{\pi}{2}\right)=\cos A=\sqrt{1-\sin^{2}A}=\sqrt{\frac{2}{3}}$，所以$c=\sqrt{6}\cdot\frac{\sqrt{2/3}}{1/3}=6$故$S_{\triangle ABC}=\frac{1}{2}AC\cdot AB\cdot\sin A =\frac{1}{2}\cdot\sqrt{6}\cdot6\cdot\frac{\sqrt{3}}{3}=3\sqrt{2}$
  15. 解答题 概率统计
    某地有$A$，$B$，$C$，$D$四人先后感染了甲型$\mathrm{H1N1}$流感. 其中只有$A$到过疫区。$B$肯定是受$A$感染的. 对于$C$，因为难以断定他是受$A$还是受$B$感染的，于是假定他受$A$和受$B$感染的概率都是$\frac{1}{2}$. 同样也假定$D$受$A$，$B$和$C$感染的概率都是$\frac{1}{3}$. 在这种假定之下，$B$，$C$，$D$中直接受$A$感染的人数$X$就是一个随机变量. 写出$X$的分布列（不要求写出计算过程），并求$X$的均值（即数学期望）。
    显示答案
    解析:
    由于$B$肯定直接受$A$感染，先计入人数$1$. 设$I_C$表示事件“$C$直接受$A$感染”，$I_D$表示事件“$D$直接受$A$感染”，则$X=1+I_C+I_D$根据题意，$P(I_C)=\frac{1}{2}$，并且无论$C$由谁感染，$D$直接受$A$感染的条件概率都是$\frac{1}{3}$. 因此$P(X=1)=P(I_C=0,I_D=0)=\frac{1}{2}\cdot\frac{2}{3}=\frac{1}{3}$$P(X=3)=P(I_C=1,I_D=1)=\frac{1}{2}\cdot\frac{1}{3}=\frac{1}{6}$当$X=2$时，有两种互斥情形：$C$直接受$A$感染而$D$不直接受$A$感染，或$C$不直接受$A$感染而$D$直接受$A$感染. 所以$P(X=2)=\frac{1}{2}\cdot\frac{2}{3}+\frac{1}{2}\cdot\frac{1}{3}=\frac{1}{2}$于是，$X$的分布列由$P(X=1)=\frac{1}{3}$，$P(X=2)=\frac{1}{2}$，$P(X=3)=\frac{1}{6}$给出，且$E(X)=1\cdot\frac{1}{3}+2\cdot\frac{1}{2}+3\cdot\frac{1}{6}=\frac{11}{6}$
  16. 解答题 立体几何
    如图，四棱锥$F - ABCD$的底面$ABCD$是菱形，其对角线$AC = 2$，$BD = \sqrt{2}$，$AE$，$CF$都与平面$ABCD$垂直，$AE = 1$，$CF = 2$. (1) 求二面角$B - AF - D$的大小； (2) 求四棱锥$E - ABCD$与四棱锥$F - ABCD$公共部分的体积。
    显示答案
    解析:
    (1) 设$AC$与$BD$交于$O$，过$O$作$OG\perp AF$，垂足为$G$，连接$BG$，$DG$. 因为菱形的对角线互相垂直，所以$BD\perp AC$. 又$CF\perp$平面$ABCD$，从而$BD\perp CF$，故$BD\perp$平面$ACF$，进而$BD\perp AF$. 因为$BD$与$OG$是平面$BGD$内相交的两条直线，且$AF\perp BD$，$AF\perp OG$，所以$AF\perp$平面$BGD$. 因此$\angle BGD$是二面角$B-AF-D$的平面角. 在三角形$AOF$中，$AO=\frac{AC}{2}=1$. 因为$AO$与$AC$共线且$CF\perp AC$，所以点$F$到直线$AO$的距离为$CF=2$，从而$AF=\sqrt{AC^{2}+CF^{2}}=2\sqrt{2}$，并且$S_{\triangle AOF}=\frac{1}{2}AO\cdot CF=1=\frac{1}{2}AF\cdot OG$得$OG=\frac{1}{\sqrt{2}}$. 又$OB=OD=\frac{BD}{2}=\frac{1}{\sqrt{2}}$，且$OB\perp OG$，$OD\perp OG$. 所以直角三角形$BOG$，$DOG$都是等腰直角三角形，$\angle BGO=\angle OGD=\frac{\pi}{4}$. 因而$\angle BGD=\angle BGO+\angle OGD=\frac{\pi}{2}$所以二面角$B-AF-D$的大小为$\frac{\pi}{2}$. (2) 连接$EB$，$EC$，$ED$，设直线$AF$与直线$CE$交于$H$. 在截面平面$ACEF$内，两个四棱锥的截面分别是三角形$EAC$和$FAC$，它们的公共部分为三角形$HAC$； 由于棱锥侧面由顶点与底面边界线性连接，故两个四棱锥的公共部分为四棱锥$H-ABCD$. 在平面$ACEF$内建立直角坐标系，以$AC$为横轴、过$A$且垂直于底面的直线为纵轴，则可取$A(0,0)$，$C(2,0)$，$E(0,1)$，$F(2,2)$. 于是直线$AF$的方程为$y=x$，直线$CE$的方程为$y=1-\frac{x}{2}$，联立得$x=1-\frac{x}{2}$，$x=\frac{2}{3}$，$y=\frac{2}{3}$. 所以点$H$到平面$ABCD$的距离为$\frac{2}{3}$. 又$S_{ABCD}=\frac{1}{2}AC\cdot BD=\frac{1}{2}\cdot2\cdot\sqrt{2}=\sqrt{2}$故公共部分的体积为$V=\frac{1}{3}S_{ABCD}\cdot\frac{2}{3}=\frac{2\sqrt{2}}{9}$
  17. 解答题 函数 · 导数
    已知函数$f(x) = x - \frac{2}{x} + a(2 - \ln x)$，$a > 0$. 讨论$f(x)$的单调性。
    显示答案
    解析:
    函数的定义域为$x>0$，且$f'(x)=1+\frac{2}{x^{2}}-\frac{a}{x}=\frac{x^{2}-ax+2}{x^{2}}$当$0<a<2\sqrt{2}$时，二次式$x^{2}-ax+2$的判别式为$a^{2}-8<0$，且二次项系数为正，所以对一切$x>0$都有$f'(x)>0$. 因此$f(x)$在$(0,+\infty)$上单调递增. 当$a=2\sqrt{2}$时，$f'(x)=\frac{(x-\sqrt{2})^{2}}{x^{2}}\geqslant0$除$x=\sqrt{2}$外均有$f'(x)>0$，所以$f(x)$仍在$(0,+\infty)$上单调递增. 当$a>2\sqrt{2}$时，令$x_{1}=\frac{a-\sqrt{a^{2}-8}}{2}$，$x_{2}=\frac{a+\sqrt{a^{2}-8}}{2}$. 因为$x_{1}x_{2}=2>0$，$x_{1}+x_{2}=a>0$，所以$0<x_{1}<x_{2}$. 此时$x^{2}-ax+2=(x-x_{1})(x-x_{2})$由于$x^{2}>0$，可得$f'(x)>0$在$(0,x_{1})$和$(x_{2},+\infty)$上成立，$f'(x)<0$在$(x_{1},x_{2})$上成立. 因而$f(x)$在$(0,x_{1})$，$(x_{2},+\infty)$上单调递增，在$(x_{1},x_{2})$上单调递减。
  18. 解答题 三角函数 · 数列 · 解析几何
    点$P(x_0, y_0)$在椭圆$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$）上，$x_0 = a \cos \beta$，$y_0 = b \sin \beta$，$0 < \beta < \frac{\pi}{2}$，直线$l_2$与直线$l_1:\ \frac{x_0}{a^2} x + \frac{y_0}{b^2} y = 1$垂直，$O$为坐标原点，直线$OP$的倾斜角为$\alpha$，直线$l_2$的倾斜角为$\gamma$. (1) 证明：点$P$是椭圆$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$与直线$l_1$的唯一交点； (2) 证明：$\tan \alpha$，$\tan \beta$，$\tan \gamma$构成等比数列。
    显示答案
    解析:
    (1) 任取椭圆上的点$Q(x,y)$，令$u=\frac{x}{a}$，$v=\frac{y}{b}$. 则$u^{2}+v^{2}=1$. 又因为$x_{0}=a\cos\beta$，$y_{0}=b\sin\beta$，所以直线$l_{1}$的方程可写为$u\cos\beta+v\sin\beta=1$由柯西不等式，$u\cos\beta+v\sin\beta \leqslant\sqrt{u^{2}+v^{2}}\sqrt{\cos^{2}\beta+\sin^{2}\beta}=1$若点$Q$在直线$l_{1}$上，上式取等号. 由于两个向量$(u,v)$，$(\cos\beta,\sin\beta)$都是单位向量，等号成立当且仅当$(u,v)=(\cos\beta,\sin\beta)$于是$x=a\cos\beta=x_{0}$，$y=b\sin\beta=y_{0}$，即$Q=P$. 因此点$P$是椭圆与直线$l_{1}$的唯一交点. (2) 因为$0<\beta<\frac{\pi}{2}$，所以$x_{0}>0$，$y_{0}>0$. 直线$OP$的斜率为$\tan\alpha=\frac{y_{0}}{x_{0}}=\frac{b}{a}\tan\beta$直线$l_{1}$的斜率为$-\frac{x_{0}/a^{2}}{y_{0}/b^{2}}$，所以与它垂直的直线$l_{2}$的斜率为$\tan\gamma=\frac{a^{2}y_{0}}{b^{2}x_{0}}=\frac{a}{b}\tan\beta$从而$\tan\alpha\tan\gamma=\left(\frac{b}{a}\tan\beta\right)\left(\frac{a}{b}\tan\beta\right)=\tan^{2}\beta$因此$\tan\alpha$，$\tan\beta$，$\tan\gamma$构成等比数列。
  19. 解答题 数列
    首项为正数的数列$\{a_n\}$满足$a_{n + 1} = \frac{1}{4} (a_n^2 + 3)$，$n\in \N_+$. (1) 证明：若$a_1$为奇数，则对一切$n \geqslant 2$，$a_n$都是奇数； (2) 若对一切$n \in \N_+$都有$a_{n+1} > a_n$，求$a_1$的取值范围。
    显示答案
    解析:
    (1) 若$a_n$为奇数，则存在整数$k$，使得$a_n^{2}=8k+1$. 由递推关系式，$a_{n+1}=\frac{a_n^{2}+3}{4}=\frac{8k+4}{4}=2k+1$所以$a_{n+1}$也是奇数. 由数学归纳法，若$a_1$为奇数，则对一切$n\geqslant2$，$a_n$都是奇数. (2) 由递推关系式，$a_{n+1}-a_n=\frac{a_n^{2}-4a_n+3}{4}=\frac{(a_n-1)(a_n-3)}{4}$因此，$a_{n+1}>a_n$等价于$a_n<1$或$a_n>3$. 若对一切正整数$n$都有$a_{n+1}>a_n$，特别地，$a_1>0$且$a_1\notin[1,3]$，所以必须有$a_1\in(0,1)\cup(3,+\infty)$反之，若$0<a_1<1$，则当$0<a_n<1$时，$a_{n+1}-a_n>0$，$0<a_{n+1}=\frac{a_n^{2}+3}{4}<1$. 由归纳法，所有$a_n$都属于$(0,1)$，且$a_{n+1}>a_n$. 若$a_1>3$，则当$a_n>3$时，$a_{n+1}-a_n>0$，$a_{n+1}=\frac{a_n^{2}+3}{4}>\frac{9+3}{4}=3$. 同样由归纳法，所有$a_n$都大于$3$，且$a_{n+1}>a_n$. 因此$a_1$的取值范围为$\boxed{(0,1)\cup(3,+\infty)}$
