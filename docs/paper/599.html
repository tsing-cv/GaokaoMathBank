    设$0 < \theta < \frac{\pi}{2}$，向量$\mathbf{a} = (\sin 2\theta, \cos \theta)$，$\mathbf{b} = (1, -\cos \theta)$，若$\mathbf{a} \cdot \mathbf{b} = 0$，则$\tan \theta =$____。
    显示答案
    答案:
    $\frac{1}{2}$
    解析:
    由向量数量积为零，得$\mathbf{a}\cdot\mathbf{b}=\sin 2\theta-\cos^2\theta=0$. 利用$\sin 2\theta=2\sin\theta\cos\theta$，有$\cos\theta(2\sin\theta-\cos\theta)=0$. 因为$0<\theta<\frac\pi2$，所以$\cos\theta>0$，从而$2\sin\theta=\cos\theta$，即$\tan\theta=\frac12$。
  14. 填空题 待标注
    已知$f(x) = \frac{x}{1 + x}$，$x \geqslant 0$，若$f_1(x) = f(x)$，$f_{n+1}(x) = f(f_n(x))$，$n \in \mathbf{N}_+$，则$f_{2014}(x)$的表达式为____。
    显示答案
    答案:
    $\frac{x}{2014x+1}$
    解析:
    先证明$f_n(x)=\frac{x}{1+nx}$. 由于$x\geqslant0$且$n\in\mathbf N_+$，有$1+nx>0$，所以各步分式均有意义. 当$n=1$时，$f_1(x)=f(x)=\frac{x}{1+x}$，结论成立. 若$f_n(x)=\frac{x}{1+nx}$，则$f_{n+1}(x)=f\left(\frac{x}{1+nx}\right) =\frac{\frac{x}{1+nx}}{1+\frac{x}{1+nx}} =\frac{x}{1+(n+1)x}$由数学归纳法，$f_n(x)=\frac{x}{1+nx}$对一切$n\in\mathbf N_+$成立. 因此$f_{2014}(x)=\frac{x}{1+2014x}=\frac{x}{2014x+1}$

  18. 解答题 三角函数 · 数列
    $\triangle ABC$的内角$A$，$B$，$C$所对的边分别为$a$，$b$，$c$. (1) 若$a$，$b$，$c$成等差数列，证明：$\sin A + \sin C = 2\sin (A + C)$； (2) 若$a$，$b$，$c$成等比数列，且$c = 2a$，求$\cos B$的值。
    显示答案
    解析:
    (1) 由正弦定理，存在$k>0$使$a=k\sin A$，$b=k\sin B$，$c=k\sin C$. 因为$a$，$b$，$c$成等差数列，所以$a+c=2b$，从而$\sin A+\sin C=2\sin B$. 又$A+B+C=\pi$，故$\sin B=\sin(A+C)$，所以$\sin A+\sin C=2\sin(A+C)$. (2) 因为$a$，$b$，$c$为三角形的边，均为正数. 设等比数列公比为$q>0$，则$b=aq$，$c=aq^2$. 由$c=2a$得$q^2=2$，所以$b=\sqrt2a$，$c=2a$. 在三角形$ABC$中对角$B$使用余弦定理，$b^2=a^2+c^2-2ac\cos B$. 代入边长关系得$2a^2=a^2+4a^2-4a^2\cos B$，所以$\cos B=\frac34$。
  19. 解答题 立体几何
    四面体$ABCD$及其三视图如图所示，过棱$AB$的中点$E$作平行于$AD$，$BC$的平面分别交四面体的棱$BD$，$DC$，$CA$于点$F$，$G$，$H$. (1) 求四面体$ABCD$的体积； (2) 证明：四边形$EFGH$是矩形。
    显示答案
    解析:
    (1) 由三视图可知，$AD\perp BD$，$AD\perp DC$，$BD\perp DC$，且$AD=1$，$BD=DC=2$. 因为$BD$、$DC$是平面$BDC$内相交的两条直线，所以直线$AD$垂直于平面$BDC$. 因而以三角形$BDC$为底，$AD$为高，四面体体积为$V=\frac13\cdot\frac12BD\cdot DC\cdot AD =\frac13\cdot\frac12\cdot2\cdot2\cdot1=\frac23$(2) 平面$EFGH$平行于$AD$和$BC$. 在三角形$ABD$中，过$E$的截线$EF\parallel AD$，且$E$为$AB$的中点，所以$F$为$BD$的中点. 在三角形$ABC$中，截线$EH\parallel BC$，所以$H$为$AC$的中点. 平面$BDC$与平面$EFGH$的交线为$FG$，且$FG\parallel BC$. 由三角形$BDC$的中位线定理，$G$为$DC$的中点. 又在三角形$ADC$中，$H$，$G$分别为$AC$，$DC$的中点，所以$HG\parallel AD$. 因此$EF\parallel HG$，$EH\parallel FG$，四边形$EFGH$为平行四边形. 由$AD\perp BC$，且$EF\parallel AD$，$FG\parallel BC$，得$EF\perp FG$. 该平行四边形有一个直角，所以四边形$EFGH$是矩形。

  22. 解答题 解析几何
    已知椭圆$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$）经过点$(0, \sqrt{3})$，离心率为$\frac{1}{2}$，左右焦点分别为$F_1(-c, 0)$，$F_2(c, 0)$. (1) 求椭圆的方程. (2) 若直线$l: y = -\frac{1}{2} x + m$与椭圆交于$A$，$B$两点，与以$F_{1}F_{2}$为直径的圆交于$C$，$D$两点，且满足$\frac{|AB|}{|CD|} = \frac{5\sqrt{3}}{4}$，求直线$l$的方程。
    显示答案
    解析:
    (1) 因为椭圆经过$(0,\sqrt3)$，所以$\frac{3}{b^2}=1$，即$b^2=3$. 又离心率$e=\frac ca=\frac12$，且$c^2=a^2-b^2$，故$\frac{a^2}{4}=a^2-3$，即$a^2=4$. 因此椭圆方程为$\frac{x^2}{4}+\frac{y^2}{3}=1$(2) 以$y=-\frac12x+m$代入椭圆方程，得$\frac{x^2}{4}+\frac{\left(-\frac12x+m\right)^2}{3}=1$即$x^2-mx+m^2-3=0$设两交点的横坐标为$x_1$，$x_2$，则$x_1+x_2=m$，$x_1x_2=m^2-3$，$(x_1-x_2)^2=3(4-m^2)$. 所以弦$AB$的长度为$|AB|=\sqrt{1+\left(-\frac12\right)^2}|x_1-x_2|=\frac{\sqrt{15}}2\sqrt{4-m^2}$由$c^2=a^2-b^2=1$，以$F_1F_2$为直径的圆为$x^2+y^2=1$. 直线$l$到原点的距离为$d=\frac{2|m|}{\sqrt5}$，故弦$CD$的长度为$|CD|=2\sqrt{1-d^2}=\frac2{\sqrt5}\sqrt{5-4m^2}$由题设，$\frac{|AB|}{|CD|}=\frac{5\sqrt3}{4}\sqrt{\frac{4-m^2}{5-4m^2}}=\frac{5\sqrt3}{4}$由于$A$、$B$和$C$、$D$均为两个交点，需有$4-m^2>0$且$5-4m^2>0$. 从而$4-m^2=5-4m^2$，即$m^2=\frac13$，所得两个值均满足上述相交条件，故$m=\pm\frac{\sqrt3}{3}$所求直线为$y=-\frac12x+\frac{\sqrt3}{3}$或$y=-\frac12x-\frac{\sqrt3}{3}$。
  23. 解答题 函数 · 导数
    设函数$f(x) = \ln x + \frac{m}{x}$，$m \in \R$. (1) 当$m = e$（$e$为自然对数的底数）时，求$f(x)$的极小值； (2) 讨论函数$g(x) = f'(x) - \frac{x}{3}$零点的个数； (3) 若对任意$b > a > 0$，$\frac{f(b) - f(a)}{b - a} < 1$恒成立，求$m$的取值范围。
    显示答案
    解析:
    (1) 当$m=e$时，$x>0$，且$f'(x)=\frac1x-\frac{e}{x^2}=\frac{x-e}{x^2}$因此$f'(x)<0$在$(0,e)$上成立，$f'(x)>0$在$(e,+\infty)$上成立，故$x=e$处取得极小值. 其值为$f(e)=\ln e+\frac{e}{e}=1+1=2$(2)$x>0$时$g(x)=\frac1x-\frac{m}{x^2}-\frac{x}{3}$由于$3x^2>0$，$g(x)=0$等价于$m=\varphi(x):=x-\frac{x^3}{3}$又$\varphi'(x)=1-x^2$所以$\varphi$在$(0,1)$上递增，在$(1,+\infty)$上递减，且$\varphi(0^+)=0$，$\varphi(1)=\frac23$，$\varphi(x)\to-\infty$（$x\to+\infty$）. 因此，当$m>\frac23$时有$0$个零点； 当$m=\frac23$或$m\leqslant0$时有$1$个零点； 当$0<m<\frac23$时有$2$个零点. (3) 令$h(x)=f(x)-x$. 题设不等式等价于对任意$b>a>0$有$h(b)<h(a)$，即$h$在$(0,+\infty)$上严格递减. 求导得$h'(x)=\frac1x-\frac{m}{x^2}-1=-\frac{x^2-x+m}{x^2}$当$m\geqslant\frac14$时，$x^2-x+m=\left(x-\frac12\right)^2+m-\frac14\geqslant0$所以$h'(x)\leqslant0$，且至多在一个点取零. 对任意$b>a>0$，$h(b)-h(a)=\int_a^b h'(x)\,\mathrm dx<0$，故$h$严格递减，题设成立. 当$m<\frac14$时，$x^2-x+m$在$x=\frac12$处为负，故在该点附近$h'(x)>0$，可以取$b>a>0$使$h(b)>h(a)$，题设不成立. 因此$m\in\left[\frac14,+\infty\right)$
