1993年全国卷（理）

1993年 · 全国 · 理科 · 真题 · 共 14 题

  1. 选择题 待标注
    当$z = -\frac{1 - i}{\sqrt{2}}$时，$z^{100} + z^{50} + 1$的值等于（ ）
    A.
    $1$
    B.
    $-1$
    C.
    $i$
    D.
    $-i$
    显示答案
    答案:
    D
    解析:
    $z=\frac{-1+i}{\sqrt{2}}=\cos\frac{3\pi}{4}+i\sin\frac{3\pi}{4}$，因此$z^{50}=\cos\frac{75\pi}{2}+i\sin\frac{75\pi}{2}=-i$，从而$z^{100}=-1$. 所以$z^{100}+z^{50}+1=-1-i+1=-i$，故选 D。
  2. 选择题 三角函数
    直线$bx + ay = ab$（$a < 0$，$b < 0$）的倾斜角是（ ）
    A.
    $\arctan \left(-\frac{b}{a}\right)$
    B.
    $\arctan \left(-\frac{a}{b}\right)$
    C.
    $\pi - \arctan \frac{b}{a}$
    D.
    $\pi - \arctan \frac{a}{b}$
    显示答案
    答案:
    C
    解析:
    由直线方程得$y=-\frac{b}{a}x+b$. 由于$a<0$，$b<0$，所以$\frac{b}{a}>0$，直线的斜率$-\frac{b}{a}<0$. 设直线的倾斜角为$\alpha$，则$0\leqslant\alpha<\pi$，且$\tan\alpha=-\frac{b}{a}<0$. 因此$\frac{\pi}{2}<\alpha<\pi$. 又因为$\arctan\frac{b}{a}\in\left(0,\frac{\pi}{2}\right)$，所以$\alpha=\pi-\arctan\frac{b}{a}$. 故选 C。
  3. 选择题 数列
    在各项均为正数的等比数列$\{a_{n}\}$中，若$a_{5}a_{6} = 9$，则$\log_{3} a_{1} + \log_{3} a_{2} + \dots + \log_{3} a_{10}$的值为（ ）
    A.
    $12$
    B.
    $10$
    C.
    $8$
    D.
    $2 + \log_{3} 5$
    显示答案
    答案:
    B
    解析:
    设等比数列的公比为$q$. 对$i=1$，$2$，$\dots$，$5$，数列通项的指数相加为$(i-1)+(10-i)=9$，所以$a_i a_{11-i}=a_5a_6=9$. 因而$\sum_{i=1}^{10}\log_3 a_i =\sum_{i=1}^{5}\log_3(a_i a_{11-i}) =5\log_3 9=10$故选 B。
  4. 选择题 函数
    $F(x) = \left(1 + \frac{2}{2^{x} - 1}\right)f(x)$（$x \neq 0$）是偶函数，且$f(x)$不恒等于零，则$f(x)$（ ）
    A.
    是奇函数
    B.
    是偶函数
    C.
    可能是奇函数也可能是偶函数
    D.
    不是奇函数也不是偶函数
    显示答案
    答案:
    A
    解析:
    令$g(x)=1+\frac{2}{2^x-1}=\frac{2^x+1}{2^x-1}$. 当$x\neq0$时，$g(-x)=-g(x)$，且$g(x)\neq0$. 由$F(x)$为偶函数，得$-g(x)f(-x)=g(x)f(x)$，约去$g(x)$后得到$f(-x)=-f(x)$. 因此$f(x)$是奇函数，故选 A。
  5. 选择题 解析几何 · 极坐标与参数方程
    曲线的参数方程为$\begin{cases} x = 3t^2 + 2,\\ y = t^2 - 1, \end{cases}$（$0 \leqslant t \leqslant 5$），则曲线是（ ）
    A.
    线段
    B.
    双曲线的一支
    C.
    圆弧
    D.
    射线
    显示答案
    答案:
    A
    解析:
    消去参数得$x=3(t^2-1)+5=3y+5$. 又因为$0\leqslant t\leqslant5$，所以$0\leqslant t^2\leqslant25$，从而$-1\leqslant y\leqslant24$. 因此曲线是直线$x=3y+5$上从$(2,-1)$到$(77,24)$的线段，故选 A。
  6. 选择题 集合与逻辑 · 三角函数
    已知集合$E = \{\theta | \cos \theta < \sin \theta, 0 \leqslant \theta \leqslant 2\pi\}$，$F = \{\theta | \tan \theta < \sin \theta\}$，那么$E \cap F$为区间（ ）
    A.
    $\left(\frac{\pi}{2},\pi\right)$
    B.
    $\left(\frac{\pi}{4},\frac{3\pi}{4}\right)$
    C.
    $\left(\pi,\frac{3\pi}{2}\right)$
    D.
    $\left(\frac{3\pi}{4},\frac{5\pi}{4}\right)$
    显示答案
    答案:
    A
    解析:
    由$\sin\theta-\cos\theta>0$及$0\leqslant\theta\leqslant2\pi$，得$E=\left(\frac{\pi}{4},\frac{5\pi}{4}\right)$. 在正切有意义时，$\tan\theta-\sin\theta=\frac{\sin\theta(1-\cos\theta)}{\cos\theta}$. 在$\left(\frac{\pi}{4},\frac{\pi}{2}\right)$内该式为正，在$\left(\frac{\pi}{2},\pi\right)$内为负，在$\left(\pi,\frac{5\pi}{4}\right)$内为正. 因此$E\cap F=\left(\frac{\pi}{2},\pi\right)$，故选 A。
  7. 选择题 解析几何
    一动圆与两圆：$x^{2} + y^{2} = 1$和$x^{2} + y^{2} - 8x + 12 = 0$都外切，则动圆圆心的轨迹为（ ）
    A.
    抛物线
    B.
    圆
    C.
    双曲线的一支
    D.
    椭圆
    显示答案
    答案:
    C
    解析:
    设动圆圆心为$M$，半径为$r$，两个定圆的圆心分别为$O_1=(0,0)$、$O_2=(4,0)$，半径分别为$1$、$2$. 两定圆圆心距为$O_1O_2=4$. 由外切条件，$MO_1=r+1$，$MO_2=r+2$，所以$MO_2-MO_1=1$. 动点到两个定点的距离之差为定值，故其轨迹为双曲线的一支，故选 C。
  8. 选择题 立体几何
    已知异面直线$a$与$b$所成的角为$50^{\circ}$，$P$为空间上一定点，则过点$P$且与$a$，$b$所成的角都是$30^{\circ}$的直线有且仅有（ ）
    A.
    $1$条
    B.
    $2$条
    C.
    $3$条
    D.
    $4$条
    显示答案
    答案:
    B
    解析:
    取两条异面直线的单位方向向量为$\mathbf{u}=(\cos25^\circ,\sin25^\circ,0)$和$\mathbf{v}=(\cos25^\circ,-\sin25^\circ,0)$. 设所求直线的单位方向向量为$\mathbf{w}=(x,y,z)$. 因为直线所成的角为$30^\circ$，有$\lvert\mathbf{w}\cdot\mathbf{u}\rvert=\lvert\mathbf{w}\cdot\mathbf{v}\rvert=\cos30^\circ$. 若两个内积同号，取同为$\cos30^\circ$（取负号只会把方向向量整体反向），两式相减得$y=0$，再由其中一式得$x=\frac{\cos30^\circ}{\cos25^\circ}<1$. 因而$z=\pm\sqrt{1-x^2}$，得到两条不同的直线. 若两个内积异号，两式相加或相减可得$x=0$，且$\lvert y\rvert=\frac{\cos30^\circ}{\sin25^\circ}>1$，这与$x^2+y^2+z^2=1$矛盾. 所以所求直线有且仅有$2$条，故选 B。
  9. 填空题 解析几何
    抛物线$y^{2} = 4x$的弦$AB$垂直于$x$轴，若$AB$的长为$4\sqrt{3}$，则焦点到$AB$的距离为____。
    显示答案
    答案:
    2
    解析:
    设弦$AB$所在的直线为$x=x_0$. 代入抛物线$y^2=4x$，弦端点的纵坐标为$\pm2\sqrt{x_0}$，所以$AB=4\sqrt{x_0}=4\sqrt3$，得$x_0=3$. 抛物线$y^2=4x$的焦点为$(1,0)$，故焦点到直线$x=3$的距离为$2$。
  10. 填空题 数列
    已知等差数列$\{a_{n}\}$的公差$d > 0$，首项$a_{1} > 0$，$S_{n} = \sum_{i=1}^{n} \frac{1}{a_{i} a_{i+1}}$，则$\displaystyle\lim_{n \to \infty} S_{n} =$____。
    显示答案
    答案:
    $\frac{1}{a_1d}$
    解析:
    设$a_i=a_1+(i-1)d$，则$a_{i+1}-a_i=d$. 因为$a_1>0$，$d>0$，所以每一项都不为零，并且$\frac{1}{a_i a_{i+1}}=\frac{1}{d}\left(\frac{1}{a_i}-\frac{1}{a_{i+1}}\right)$于是$S_n=\frac{1}{d}\sum_{i=1}^{n}\left(\frac{1}{a_i}-\frac{1}{a_{i+1}}\right)=\frac{1}{d}\left(\frac{1}{a_1}-\frac{1}{a_{n+1}}\right)$又因为$a_{n+1}=a_1+nd\to+\infty$，所以$\frac{1}{a_{n+1}}\to0$. 因而$\lim_{n\to\infty}S_n=\frac{1}{a_1d}$故填$\frac{1}{a_1d}$。
  11. 解答题 不等式
    解不等式：$2 + \log_{\frac{1}{2}}(5 - x) + \log_{2}\frac{1}{x} > 0$。
    显示答案
    解析:
    由对数的真数必须为正，得$5-x>0$，$x>0$， 所以定义域为$0<x<5$. 在此范围内，利用换底关系和倒数的对数性质，原不等式等价于$2-\log_{2}(5-x)-\log_{2}x>0$即$\log_{2}\bigl(x(5-x)\bigr)<2$由于底数$2>1$，这又等价于$x(5-x)<4$从而$x^2-5x+4>0$，即$(x-1)(x-4)>0$. 结合定义域$0<x<5$，得$x\in(0,1)\cup(4,5)$. 故原不等式的解集为$(0,1)\cup(4,5)$。
  12. 解答题 立体几何
    如图，$A_{1}B_{1}C_{1}-ABC$是直三棱柱，过点$A_{1}$，$B$，$C_{1}$的平面和平面$ABC$的交线记作$l$. (1) 判定直线$A_{1}C_{1}$和$l$的位置关系，并加以证明； (2) 若$A_{1}A = 1$，$AB = 4$，$BC = 3$，$\angle ABC = 90^{\circ}$，求顶点$A_{1}$到直线$l$的距离。
    显示答案
    解析:
    (1) 建立空间直角坐标系，使$B=(0,0,0)$，$BA$为$x$轴正方向，$BC$为$y$轴正方向，且$AA_1$为$z$轴方向. 由题设可取$A=(4,0,0)$，$C=(0,3,0)$，$A_1=(4,0,1)$，$C_1=(0,3,1)$. 于是直线$A_1C_1$的方向向量为$(-4,3,0)$. 过$A_1$，$B$，$C_1$的平面由向量$(4,0,1)$和$(0,3,1)$张成，其方程为$3x+4y-12z=0$它与平面$ABC$（即$z=0$）的交线$l$满足$3x+4y=0$因此$l$的一个方向向量为$(4,-3,0)$，与$(-4,3,0)$平行. 所以$A_1C_1\parallel l$. (2) 直线$l$经过$B$，方向向量可取$\mathbf{u}=(4,-3,0)$. 点$A_1$的位置向量为$\overrightarrow{BA_1}=(4,0,1)$. 点到直线的距离为$\frac{\left\|\overrightarrow{BA_1}\times\mathbf{u}\right\|}{\left\|\mathbf{u}\right\|} =\frac{\left\|(3,4,-12)\right\|}{5} =\frac{13}{5}$故顶点$A_1$到直线$l$的距离为$\frac{13}{5}$。
  13. 解答题 三角函数 · 解析几何
    在面积为$1$的$\triangle PMN$中，$\tan M = \frac{1}{2}$，$\tan N = -2$，建立适当的坐标系，求出以$M$，$N$为焦点且过点$P$的椭圆方程。
    显示答案
    解析:
    建立直角坐标系，使$M=(-c,0)$，$N=(c,0)$，并取点$P$在$x$轴上方. 记三角形的内角仍为$M$，$N$，$P$. 因为$M$为锐角，$N$为钝角，且$\tan M=\frac{1}{2}$，$\tan N=-2=-\frac{1}{\tan M}$， 所以$N=\frac{\pi}{2}+M$，从而$P=\pi-M-N=\frac{\pi}{2}-2M$. 由$\tan M=\frac{1}{2}$，得$\sin M=\frac{1}{\sqrt{5}}$，$\cos M=\frac{2}{\sqrt{5}}$，$\sin N=\frac{2}{\sqrt{5}}$. 又有$\sin P=\cos 2M=\frac{3}{5}$，$\cos P=\sin 2M=\frac{4}{5}$. 由正弦定理，$PM:PN=\sin N:\sin M=2:1$. 设$PN=t$，则$PM=2t$. 由三角形面积为$1$，有$1=\frac{1}{2}\cdot PM\cdot PN\cdot\sin P=t^2\cdot\frac{3}{5}$所以$t^2=\frac{5}{3}$. 再由余弦定理，$MN^2=PM^2+PN^2-2\cdot PM\cdot PN\cdot\cos P =5t^2-\frac{16}{5}t^2=3$即$MN=\sqrt{3}$. 另一方面，点$P$在所求椭圆上，所以椭圆的长轴长满足$2a=PM+PN=3t=\sqrt{15}$因此$a=\frac{\sqrt{15}}{2}$，而两个焦点间距为$2c=MN=\sqrt{3}$，故$c=\frac{\sqrt{3}}{2}$. 于是$b^2=a^2-c^2=\frac{15}{4}-\frac{3}{4}=3$所求椭圆方程为$\frac{x^2}{15/4}+\frac{y^2}{3}=1$
  14. 解答题 待标注
    已知关于$x$的实系数二次方程$x^{2} + ax + b = 0$有两个实数根$\alpha$，$\beta$. 证明： (1) 如果$|\alpha| < 2$，$|\beta| < 2$，那么$2|\alpha| < 4 + b$且$|b| < 4$； (2) 如果$2|\alpha| < 4 + b$且$|b| < 4$，那么$|\alpha| < 2$，$|\beta| < 2$。
    显示答案
    解析:
    按原题面，两个待证命题均不成立，因而不能给出它们的证明. 由韦达定理$b=\alpha\beta$，逐条构造反例即可； 这里保留原题印刷的根$\alpha$，不把它改写为二次方程的系数$a$. (1) 取$\alpha=\frac{3}{2}$，$\beta=-\frac{19}{10}$，则$|\alpha|<2$，$|\beta|<2$，且对应的实系数二次方程为$x^2-\left(\alpha+\beta\right)x+\alpha\beta=x^2+\frac{2}{5}x-\frac{57}{20}=0$但是$2|\alpha|=3>\frac{23}{20}=4+b$，而$|b|=\frac{57}{20}<4$. 所以第（1）条中的第一个不等式不成立. (2) 取$\alpha=\frac{5}{2}$，$\beta=\frac{3}{2}$，则对应的实系数二次方程为$x^2-4x+\frac{15}{4}=0=(x-\tfrac{5}{2})(x-\tfrac{3}{2})$此时$2|\alpha|=5<\frac{31}{4}=4+b$，$|b|=\frac{15}{4}<4$， 但$|\alpha|=\frac{5}{2}>2$. 所以第（2）条的结论也不成立. 因此，第29题的原题面存在客观矛盾； 本稿保留原题面，不能将其改写成另一道题. 若把题中的$2|\alpha|$改成系数条件$2|a|$，则会得到另一条可证明的命题，但不属于原卷的文字。
