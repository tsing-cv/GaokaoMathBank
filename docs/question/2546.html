题目 #20

1999年 · 1999年广东卷 · 解答题 待标注

如图为一台冷轧机的示意图. 冷轧机由若干对轧辊组成，带钢从一端输入，经过各对轧辊逐步减薄后输出. (1) 输入带钢的厚度为$\alpha$，输出带钢的厚度为$\beta$，若每对轧辊的减薄率不超过$r_0$. 问冷轧机至少需要安装多少对轧辊？（一对轧辊减薄率$=\dfrac{\text{输入该对的带钢厚度}-\text{从该对输出的带钢厚度}}{\text{输入该对的带钢厚度}}$） (2) 已知一台冷轧机共有$4$对减薄率为$20\%$的轧辊，所有轧辊周长均为$1600\mathrm{~mm}$. 若第$k$对轧辊有缺陷，每滚动一周在带钢上压出一个疵点，在冷轧机输出的带钢上，疵点的间距为$L_k$. 为了便于检修，请计算$L_1$，$L_2$，$L_3$并填入下表（轧钢过程中，带钢宽度不变，且不考虑损耗）。$\begin{array}{|c|c|c|c|c|} \hline 轧辊序号k&1&2&3&4\\ \hline 疵点间距L_k（单位：\mathrm{mm}） &\underline{ } &\underline{ } &\underline{ } &1600\\ \hline \end{array}$
答案与解析
解析:
(1) 设需要安装$n$对轧辊. 按每对轧辊的最大减薄率$r_0$计算，厚度为$\alpha$的带钢经过$n$对轧辊后，输出厚度为$\alpha(1-r_0)^n$. 要使输出厚度不超过$\beta$，只需$\alpha(1-r_0)^n\le \beta$. 因此$n\lg(1-r_0)\le\lg\beta-\lg\alpha$由于$0<1-r_0<1$，有$\lg(1-r_0)<0$，不等号两边同除以它后方向改变，得到$n\ge \dfrac{\lg\beta-\lg\alpha}{\lg(1-r_0)}$. 所以至少需要安装$\left\lceil\frac{\lg\beta-\lg\alpha}{\lg(1-r_0)}\right\rceil$对轧辊. (2) 因带钢宽度不变且不考虑损耗，体积守恒. 第$k$对轧辊出口处两疵点间带钢的体积为$1600\mathrm{~mm}\cdot \alpha(1-r)^k\cdot \text{宽度}$（$r=20\%$）， 而在冷轧机输出端对应的体积为$L_k\cdot \alpha(1-r)^4\cdot \text{宽度}$. 故$1600\mathrm{~mm}\cdot \alpha(1-r)^k=L_k\cdot \alpha(1-r)^4$， 从而$L_k=1600\mathrm{~mm}\cdot 0.8^{\,k-4}$. 于是$L_3=2000\mathrm{~mm}$，$L_2=2500\mathrm{~mm}$，$L_1=3125\mathrm{~mm}$，表中从第$1$对到第$4$对依次填$3125$，$2500$，$2000$，$1600$。
