题目 #18

2013年 · 2013年广东卷（理） · 解答题 三角函数立体几何

如图(1)，在等腰直角三角形$ABC$中，$\angle A = 90^{\circ}$，$BC = 6$。$D$，$E$分别是$AC$，$AB$上的点，$CD = BE = \sqrt{2}$，$O$为$BC$的中点. 将$\triangle ADE$沿$DE$折起，得到下图(2)所示的四棱锥$A^{\prime} - BCDE$，其中$A^{\prime}O = \sqrt{3}$. (1) 证明：$A^{\prime}O \perp$平面$BCDE$. (2) 求二面角$A^{\prime} - CD - B$的平面角的余弦值。
答案与解析
解析:
(1) 取平面$BCDE$为$xOy$平面，令$O$为原点，$BC$在$x$轴上. 由于$BC=6$，可取$B=(3,0,0)$，$C=(-3,0,0)$. 在折叠前，等腰直角三角形可取$A=(0,-3,0)$，因为$AB=AC=3\sqrt2$. 由$CD=BE=\sqrt2$，得$D=(-2,-1,0)$，$E=(2,-1,0)$； 折叠沿$DE$进行不会改变这些底面点的坐标. 设$A^{\prime}=(u,v,h)$. 折叠保持$A^{\prime}D=AD=2\sqrt2$和$A^{\prime}E=AE=2\sqrt2$，故$(u+2)^2+(v+1)^2+h^2=(u-2)^2+(v+1)^2+h^2$，从而$u=0$. 又已知$A^{\prime}O=\sqrt3$，所以$v^2+h^2=3$. 再由$A^{\prime}D^2=8$，得$4+(v+1)^2+h^2=8$. 与$v^2+h^2=3$相减，得$2v=0$，即$v=0$，于是$h^2=3$. 因此$A^{\prime}=(0,0,\sqrt3)$，直线$A^{\prime}O$是$z$轴，故$A^{\prime}O\perp$平面$BCDE$. (2) 取平面$BCD$的法向量$\mathbf{n}_2=(0,0,1)$. 在平面$A^{\prime}CD$内，取$\overrightarrow{CD}=(1,-1,0)$，$\overrightarrow{CA^{\prime}}=(3,0,\sqrt3)$，则该平面的一个法向量为$\mathbf{n}_1=\overrightarrow{CD}\times\overrightarrow{CA^{\prime}}=(-\sqrt3,-\sqrt3,3)$. 所以二面角的平面角$\varphi$的余弦的绝对值为$\cos\varphi=\frac{|\mathbf{n}_1\cdot\mathbf{n}_2|}{|\mathbf{n}_1||\mathbf{n}_2|}=\frac{3}{\sqrt{3+3+9}}=\frac{3}{\sqrt{15}}=\frac{\sqrt{15}}5$。
