题目 #16

2013年 · 2013年福建卷（文） · 填空题 集合与逻辑函数

设$S$，$T$是$\R$的两个非空子集. 如果存在一个从$S$到$T$的函数$y = f(x)$满足： ①$T = \{f(x)\mid x\in S\}$； ② 对任意$x_{1}$，$x_{2} \in S$，当$x_{1} < x_{2}$时，恒有$f(x_{1}) < f(x_{2})$， 那么称这两个集合“保序同构”. 现给出以下 3 对集合： ①$A = \N$，$B = \N^{*};$②$A = \{x\mid -1\leqslant x\leqslant 3\}$，$B = \{x\mid -8\leqslant x\leqslant 10\}$； ③$A = \{x \mid 0 < x < 1\}$，$B = \R$. 其中，“保序同构”的集合对的序号是____. （写出所有“保序同构”的集合对的序号）
答案与解析
答案:
$\text{(1)}\text{(2)}\text{(3)}$
解析:
对第$\text{(1)}$对集合，按$\N=\{0,1,2,\ldots\}$、$\N^{*}=\{1,2,3,\ldots\}$取$f(x)=x+1$. 该函数严格递增，且值域为$\N^{*}$，所以第$\text{(1)}$对保序同构. 对第$\text{(2)}$对集合，取$f(x)=\frac92(x+1)-8=\frac92x-\frac72$它把$[-1,3]$的两个端点分别映为$-8,10$，并且斜率为正，所以严格递增且值域为$[-8,10]$，第$\text{(2)}$对保序同构. 对第$\text{(3)}$对集合，取$f(x)=\tan\left(\pi x-\frac\pi2\right)$，$0
