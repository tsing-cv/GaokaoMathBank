题目 #11

2025年 · 2025年全国I卷 · 选择题 三角函数

已知$\triangle ABC$的面积为$\frac{1}{4}$，若$\cos 2A + \cos 2B + 2\sin C = 2$，$\cos A \cos B \sin C = \frac{1}{4}$，则（ ）
A.
$\sin C = \sin^2 A + \sin^2 B$
B.
$AB = \sqrt{2}$
C.
$\sin A + \sin B = \frac{\sqrt{6}}{2}$
D.
$AC^2 + BC^2 = 3$
答案与解析
答案:
ABC
解析:
$\cos 2A + \cos 2B + 2\sin C = 2$，由二倍角公式，$1 - 2\sin^2 A + 1 - 2\sin^2 B + 2\sin C = 2$，整理可得$\sin C = \sin^2 A + \sin^2 B$，故 A 选项正确. 由诱导公式，$\sin (A + B) = \sin (\pi - C) = \sin C$，展开可得$\sin A \cos B + \sin B \cos A = \sin^2 A + \sin^2 B$，即$\sin A (\sin A - \cos B) + \sin B (\sin B - \cos A) = 0$. 又由$\cos A\cos B\sin C=\frac{1}{4}>0$得$\cos A\cos B>0$，而三角形中不可能有两个钝角，所以$A$，$B$均为锐角. 下证$C = \frac{\pi}{2}$。$法一$分类讨论. 若$A + B = \frac{\pi}{2}$，则$\cos B=\sin\left(\frac{\pi}{2}-B\right)=\sin A$，$\cos A=\sin\left(\frac{\pi}{2}-A\right)=\sin B$， 从而等式成立； 若$A + B < \frac{\pi}{2}$，即$A < \frac{\pi}{2} - B$，由诱导公式和正弦函数的单调性得$\sin A < \cos B$，$\sin B < \cos A$， 又$\sin A > 0$，$\sin B > 0$，于是$\sin A (\sin A - \cos B) + \sin B (\sin B - \cos A) < 0$， 与条件不符，则$A + B < \frac{\pi}{2}$不成立； 若$A + B > \frac{\pi}{2}$，则$\sin A > \cos B$，$\sin B > \cos A$，$\sin A (\sin A - \cos B) + \sin B (\sin B - \cos A) > 0$， 则$A + B > \frac{\pi}{2}$不成立. 上面已经排除了$A+B<\frac{\pi}{2}$和$A+B>\frac{\pi}{2}$两种情形，所以只能有$A + B = \frac{\pi}{2}$， 即$C = \frac{\pi}{2}$。$法二$边角转化. 由$\sin C = \sin^2 A + \sin^2 B$时，由$C \in (0,\pi)$，则$\sin C \in (0,1]$，于是$1 \times \sin C = \sin^2 A + \sin^2 B \ge \sin^2 C$由正弦定理，$a^2 + b^2 \ge c^2$由余弦定理$\cos C=\frac{a^2+b^2-c^2}{2ab}\ge 0$， 故$C \in (0,\pi/2]$. 若$C \in (0,\pi/2)$，则$A + B > \pi/2$. 注意到$\cos A \cos B \sin C = \frac{1}{4}$则$\cos A \cos B > 0$于是$\cos A > 0$，$\cos B > 0$（两者同负会有两个钝角，不成立），故$A$，$B \in (0, \pi/2)$A > \frac{\pi}{2} - B$\sin A > \sin \left(\frac{\pi}{2} - B\right) = \cos B > 0$\sin C=\sin^2 A+\sin^2 B>\cos^2 B+\sin^2 B=1$与$\sin C \le 1$矛盾，故$C \in (0,\pi/2)$不成立，则$C = \frac{\pi}{2}$. 方法三：结合射影定理（方法一改进）. 由$\sin C = \sin^2 A + \sin^2 B$，结合正弦定理可得$c = a \sin A + b \sin B$，由射影定理可得$c = a \cos B + b \cos A$. 于是$a \sin A + b \sin B = a \cos B + b \cos A$，即$a(\sin A - \cos B) + b(\sin B - \cos A) = 0$. 再按方法一中对$A+B$与$\frac{\pi}{2}$的分类讨论，可推出$A + B = \frac{\pi}{2}$. 方法四：和差化积（方法一改进）. 由$a(\sin A - \cos B) + b(\sin B - \cos A) = 0$，由于$a>0$，$b>0$，且$a(\sin A-\cos B)+b(\sin B-\cos A)=0$，所以$\sin A-\cos B$与$\sin B-\cos A$不可能同时为正，也不可能同时为负，因此$(\sin A - \cos B)(\sin B - \cos A) \le 0$. 展开可得$\sin A \sin B - \sin A \cos A - \cos B \sin B + \cos A \cos B \le 0$，即$\cos (A - B) - \frac{1}{2}(\sin 2A + \sin 2B) \le 0$. 结合和差化积，$\cos (A - B)(1 - \sin (A + B)) \le 0$. 由上述分析，$A$，$B \in \left(0,\frac{\pi}{2}\right)$，则$A - B \in (-\pi/2,\pi/2)$，所以$\cos (A - B) \ge 0$，则$1 - \sin (A + B) \le 0$，即$\sin C \ge 1$. 所以$\sin C = 1$，而$C\in(0,\pi)$，在这个区间内满足$\sin C=1$的角只有$C=\frac{\pi}{2}$. 由$\cos A \cos B \sin C = \frac{1}{4} = \cos A \cos B$和$A + B = \frac{\pi}{2}$得$\cos B=\sin A$，$\sin A \cos A=\frac{1}{4}$，$\sin 2A=\frac{1}{2}$. 又因为$A+B=\frac{\pi}{2}$，所以$\sin B=\sin\left(\frac{\pi}{2}-A\right)=\cos A$. 从而$\sin B\cos B=\sin A\cos A=\frac{1}{4}$， 所以$\sin 2B=2\sin B\cos B=\frac{1}{2}$. 由于$A+B=\frac{\pi}{2}$，故$\{2A,2B\}=\left\{\frac{\pi}{6},\frac{5\pi}{6}\right\}$，从而$\{A,B\}=\left\{\frac{\pi}{12},\frac{5\pi}{12}\right\}$. 由两角和公式$\sin \frac{\pi}{12} + \sin \frac{5\pi}{12} = \frac{\sqrt{6} - \sqrt{2}}{4} + \frac{\sqrt{6} + \sqrt{2}}{4} = \frac{\sqrt{6}}{2}$故 C 正确. 不妨设$A=\frac{\pi}{12}$，$B=\frac{5\pi}{12}$. 再设$BC = t$，则$AC = (2 + \sqrt{3})t$，且$AB = (\sqrt{2} + \sqrt{6})t$由$S_{\triangle ABC} = \frac{1}{2}(2 + \sqrt{3})t^2 = \frac{1}{4}$得$t^2=\frac{4 - 2\sqrt{3}}{4}=\left(\frac{\sqrt{3} - 1}{2}\right)^2$于是$t = \frac{\sqrt{3} - 1}{2}$AB = (\sqrt{6} + \sqrt{2})t = \sqrt{2}$所以 B 正确. 又因为$AC=(2+\sqrt{3})t$，$BC=t$，$AB=\sqrt{2}$， 且$AC^2+BC^2=\left[(2+\sqrt{3})^2+1\right]t^2=(8+4\sqrt{3})t^2$. 把$t=\frac{\sqrt{3}-1}{2}$代入，得$AC^2+BC^2=(8+4\sqrt{3})\left(\frac{\sqrt{3}-1}{2}\right)^2=2=AB^2$由勾股定理逆定理可得$\angle C=\frac{\pi}{2}$. 故 D 错误。故选：ABC。
