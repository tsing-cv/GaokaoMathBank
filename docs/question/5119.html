题目 #22

2006年 · 2006年辽宁卷（文） · 解答题 解析几何向量

已知点$A(x_{1},y_{1})$，$B(x_{2},y_{2})$（$x_{1}\neq 0$，$x_{2}\neq 0$）是抛物线$y^{2} = 2px$（$p > 0$）上的两个动点。$O$是坐标原点，向量$\overrightarrow{OA}$，$\overrightarrow{OB}$满足$\left|\overrightarrow{OA} +\overrightarrow{OB}\right| = \left|\overrightarrow{OA} -\overrightarrow{OB}\right|$，设圆$C$的方程为$x^{2} + y^{2} - (x_{1} + x_{2})x - (y_{1} + y_{2})y = 0$. (1) 证明线段$AB$是圆$C$的直径； (2) 当圆$C$的圆心到直线$x - 2y = 0$的距离的最小值为$\frac{2\sqrt{5}}{5}$时，求$p$的值。
答案与解析
解析:
(1) 设$\mathbf{u}=\overrightarrow{OA}$，$\mathbf{v}=\overrightarrow{OB}$. 由已知$\lvert\mathbf{u}+\mathbf{v}\rvert=\lvert\mathbf{u}-\mathbf{v}\rvert$，两边平方并化简得$\mathbf{u}\cdot\mathbf{v}=0$，即$x_1x_2+y_1y_2=0$. 圆$C$的方程可写为$\left(x-\frac{x_1+x_2}{2}\right)^2+\left(y-\frac{y_1+y_2}{2}\right)^2=\frac{(x_1-x_2)^2+(y_1-y_2)^2}{4}$所以圆心是线段$AB$的中点. 又由$x_1x_2+y_1y_2=0$，代入点$A$的坐标可得$x_1^2+y_1^2-(x_1+x_2)x_1-(y_1+y_2)y_1=-(x_1x_2+y_1y_2)=0$故$A$在圆$C$上； 同理$B$也在圆$C$上. 因此$AB$经过圆心且端点在圆上，线段$AB$是圆$C$的直径. (2) 设$y_1=u$，$y_2=v$. 由抛物线方程，$x_1=\dfrac{u^2}{2p}$，$x_2=\dfrac{v^2}{2p}$. 由于$x_1$，$x_2\neq0$，有$u$，$v\neq0$. 正交条件给出$\frac{u^2v^2}{4p^2}+uv=0$从而$uv=-4p^2$. 令$s=u+v$，则$x_1+x_2=\frac{u^2+v^2}{2p}=\frac{s^2+8p^2}{2p}=\frac{s^2}{2p}+4p$，$y_1+y_2=s$. 圆心到直线$x-2y=0$的距离为$d(s)=\frac{\left|x_1+x_2-2(y_1+y_2)\right|}{2\sqrt5}=\frac{\left|(s-2p)^2+4p^2\right|}{4p\sqrt5}$其中分子恒为正，且$s$可取任意实数，所以当$s=2p$时取得最小值，且$d_{\min}=\frac{4p^2}{4p\sqrt5}=\frac{p}{\sqrt5}$由题设$d_{\min}=\dfrac{2\sqrt5}{5}=\dfrac{2}{\sqrt5}$，得$p=2$。
