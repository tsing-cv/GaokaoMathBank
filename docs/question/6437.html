题目 #21

2008年 · 2008年广东卷（文） · 解答题 数列

设数列$\{a_n\}$满足$a_1 = 1$，$a_2 = 2$，$a_n = \frac{1}{3}(a_{n-1} + 2a_{n-2})$（$n = 3$，$4$，$\cdots$）. 数列$\{b_n\}$满足$b_1 = 1$，$b_n$（$n = 2$，$3$，$\cdots$）是非零整数，且对任意的正整数$m$和自然数$k$，都有$-1 \leqslant b_m + b_{m+1} + \cdots + b_{m+k} \leqslant 1$. (1) 求数列$\{a_n\}$和$\{b_n\}$的通项公式； (2) 若$c_n = na_nb_n$（$n = 1$，$2$，$\dots$），求数列$\{c_n\}$的前$n$项和$S_n$。
答案与解析
解析:
(1) 将递推式改写为$3a_n-a_{n-1}-2a_{n-2}=0$. 其特征方程为$3r^2-r-2=0$，即$(r-1)(3r+2)=0$，所以两个特征根为$1$和$-\frac23$. 因此设$a_n=A+B\left(-\frac23\right)^{n-1}$. 代入前两项得$A+B=1$，$A-\frac23B=2$. 两式相减得$-\frac53B=1$，所以$B=-\frac35$，再由$A+B=1$得$A=\frac85$. 从而$a_n=\frac85-\frac35\left(-\frac23\right)^{n-1}$. 在题设中取$k=0$，得到$-1\leqslant b_m\leqslant1$. 由于$b_m$是非零整数，所以$b_m$只能取$-1$或$1$. 再取$k=1$，有$-1\leqslant b_m+b_{m+1}\leqslant1$. 两项都属于$\{-1,1\}$，故它们不能同号，只能满足$b_{m+1}=-b_m$. 结合$b_1=1$，逐项得到$b_n=(-1)^{n+1}$. 反过来，交错数列从任意一项开始的连续和在区间$[-1,1]$内：当连续项数为偶数时和为$0$，当连续项数为奇数时和为首项$1$或$-1$，所以它确实满足题设条件. (2) 由$a_n$与$b_n$的通项公式，$c_n=na_nb_n=\frac85n(-1)^{n+1}-\frac35n\left(\frac23\right)^{n-1}$. 因而$S_n=\frac85\sum_{k=1}^n k(-1)^{k+1}-\frac35\sum_{k=1}^n k\left(\frac23\right)^{k-1}$. 先计算交错和. 将相邻两项配对可得$\displaystyle\sum_{k=1}^n k(-1)^{k+1}=\begin{cases} -\frac n2,&n\text{ 为偶数},\\[2pt] \frac{n+1}{2},&n\text{ 为奇数}, \end{cases}$这也可统一写成$\displaystyle\frac{1+(-1)^{n+1}(2n+1)}4$. 对于任意$r\neq1$，由有限等比数列和$\displaystyle\sum_{k=1}^n r^k=\frac{r-r^{n+1}}{1-r}$对$r$求导，得$\displaystyle\sum_{k=1}^n kr^{k-1}=\frac{1-(n+1)r^n+nr^{n+1}}{(1-r)^2}$. 令$r=\frac23$，则$\displaystyle\sum_{k=1}^n k\left(\frac23\right)^{k-1}=9\left[1-(n+1)\left(\frac23\right)^n+n\left(\frac23\right)^{n+1}\right]=9-3(n+3)\left(\frac23\right)^n$. 代回$S_n$，分别化简两部分，得到$S_n=\frac85\cdot\frac{1+(-1)^{n+1}(2n+1)}4-\frac35\left[9-3(n+3)\left(\frac23\right)^n\right]$$=-5+\frac25(-1)^{n+1}(2n+1)+\frac95(n+3)\left(\frac23\right)^n$。
