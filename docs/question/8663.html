题目 #22

2010年 · 2010年浙江卷（理） · 解答题 函数导数数列

已知$a$是给定的实常数，设函数$f(x) = (x - a)^2 (x + b)e^x$，$b \in \R$，$x = a$是$f(x)$的一个极大值点. (1) 求$b$的取值范围； (2) 设$x_{1}$，$x_{2}$，$x_{3}$是$f(x)$的 3 个极值点. 问是否存在实数$b$，可找到$x_{4} \in \R$，使得$x_{1}$，$x_{2}$，$x_{3}$，$x_{4}$的某种排列$x_{i_{1}}$，$x_{i_{2}}$，$x_{i_{3}}$，$x_{i_{4}}$（其中$\{i_{1}, i_{2}, i_{3}, i_{4}\} = \{1, 2, 3, 4\}$）依次成等差数列？若存在，求所有的$b$及相应的$x_4$；若不存在，说明理由。
答案与解析
解析:
令$g(x)=x^2+(b-a+3)x-ab+2b-a$求导得$f'(x)=e^x(x-a)g(x)$且$\Delta_g=(b-a+3)^2-4(-ab+2b-a)=(a+b-1)^2+8>0$所以$g$有两个不等实根. (1) 在$x=a$处，若$g(a)>0$，则$f'$在该点左负右正，$x=a$是极小值点； 若$g(a)=0$，则$x-a$至少是二重因子，导数在该点不变号，也不是极值点. 因此必须$g(a)<0$. 计算得$g(a)=2(a+b)$故$b<-a$(2) 记$g$的两个根为$u<v$. 由$g(a)<0$知$u<a<v$，所以三个极值点按大小规律为$u$，$a$，$v$. 令$p=a-u>0$，$q=v-a>0$，$s=a+b$. 将$g(a+t)$展开，得$g(a+t)=t^2+(s+3)t+2s$因此$-pq=2s$，$-p+q=-(s+3)$即$q-p=\frac{pq}{2}-3.$四个数形成等差数列时，按四项从小到大排列，$u$，$a$，$v$只能占据以下三种位置类型. 第一种，$u$，$a$，$v$是连续的前三项或连续的后三项. 此时$p=q$，由（1）得$p^2=6$，所以$s=-\frac{pq}{2}=-3$，$b=-a-3$. 缺少的第四项为$x_4=a-2\sqrt6\quad\text{或}\quad x_4=a+2\sqrt6$第二种，排列为$u$，$a$，$x_4$，$v$. 此时$q=2p$，代入（1）得$p=p^2-3$，$p=\frac{1+\sqrt{13}}2$. 于是$b=-a+s=-a-p^2=-a-\frac{7+\sqrt{13}}2$，$x_4=a+p=a+\frac{1+\sqrt{13}}2$. 第三种，排列为$u$，$x_4$，$a$，$v$. 此时$p=2q$，代入（1）得$-q=q^2-3$，$q=\frac{\sqrt{13}-1}{2}$. 于是$b=-a-q^2=-a-\frac{7-\sqrt{13}}2$，$x_4=a-q=a+\frac{1-\sqrt{13}}2$. 以上各值均满足$b<-a$，且三种位置类型已经涵盖$u$，$a$，$v$在四项等差数列中的全部可能位置. 因此确实存在，所有结果为$\begin{aligned} b&=-a-3, &x_4&=a\pm2\sqrt6;\\ b&=-a-\frac{7+\sqrt{13}}2, &x_4&=a+\frac{1+\sqrt{13}}2;\\ b&=-a-\frac{7-\sqrt{13}}2, &x_4&=a+\frac{1-\sqrt{13}}2. \end{aligned}$
