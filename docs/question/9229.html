题目 #22

2011年 · 2011年上海卷（秋理） · 解答题 集合与逻辑数列排列组合

已知数列$\{a_n\}$和$\{b_n\}$的通项公式分别为$a_n = 3n + 6$，$b_n = 2n + 7$（$n \in \mathbf\{N\}^\{*\}$），将集合$\{x \mid x = a_n, n \in \mathbf\{N\}^\{*\}\} \cup \{x \mid x = b_n, n \in \mathbf\{N\}^\{*\}\}$中的元素从小到大依次排列，构成数列$c_1$，$c_2$，$c_3$，$c_4$，$\cdots$，$c_n$，$\cdots$. (1) 求$c_1$，$c_2$，$c_3$，$c_4$； (2) 求证：在数列$\{a_n\}$中，但不在数列$\{b_n\}$中的项恰为$a_2$，$a_4$，$\cdots$，$a_\{2n\}$，$\cdots$； (3) 求数列$\{c_n\}$的通项公式。
答案与解析
解析:
(1)$a_1=9$，$a_2=12$，$b_1=9$，$b_2=11$，$b_3=13$. 合并集合时重复的$9$只保留一次，所以$c_1=9$，$c_2=11$，$c_3=12$，$c_4=13$. (2) 若$a_n$也是$\{b_n\}$中的项，则存在$m\in\N^*$使$3n+6=2m+7$即$m=\dfrac\{3n-1\}\{2\}$. 当$n=2k+1$为奇数时，$m=3k+1\in\N^*$，所以$a_\{2k+1\}=b_\{3k+1\}$. 当$n=2k$为偶数时，$\dfrac\{3n-1\}\{2\}=3k-\dfrac12$不是整数，故$a_\{2k\}$不在$\{b_n\}$中. 因而所求各项恰为$a_2$，$a_4$，$\ldots$，$a_\{2k\}$，$\ldots$. (3) 由上一步，奇数项$a_\{2k-1\}=6k+3$与$b_\{3k-2\}=6k+3$重合，偶数项$a_\{2k\}=6k+6$不重合. 另外$b_\{3k-1\}=6k+5$，$b_\{3k\}=6k+7$. 所以每四个相邻的不同元素依次为$6k+3<6k+5<6k+6<6k+7$，从而$c_n=\begin\{cases\} 6k+3,&n=4k-3,\\ 6k+5,&n=4k-2,\\ 6k+6,&n=4k-1,\\ 6k+7,&n=4k, \end\{cases\}\qquad k\in\N^*$
