题目 #17

2025年 · 2025年全国I卷 · 解答题 三角函数立体几何

如图所示的四棱锥$P - ABCD$中，$PA \perp \text{平面} ABCD$，$BC \parallel AD$，$AB \perp AD$. (1) 证明：平面$PAB \perp \text{平面} PAD$； (2)$PA = AB = \sqrt{2}$，$BC = 2$，$AD = 1 + \sqrt{3}$，点$P$，$B$，$C$，$D$均在球$O$的球面上. (1) 证明：$O$在平面$ABCD$上； (2) 求直线$AC$与直线$PO$所成角的余弦值。
答案与解析
解析:
(1) 由题意证明如下，在四棱锥$P - ABCD$中，$PA \perp \text{平面} ABCD$，$AB \perp AD$，因为$AB \subset \text{平面} ABCD$，$AD \subset \text{平面} ABCD$，所以$PA \perp AB$，$PA \perp AD$. 又$AB \perp AD$，且$PA \cap AD = A$，所以$AB \perp \text{平面} PAD$. 因为$AB \subset \text{平面} PAB$，所以平面$PAB \perp \text{平面} PAD$. (2) (1) 由题意及（1）证明如下。$法一$在四棱锥$P - ABCD$中，$AP \perp AB$，$AP \perp AD$，$AB \perp AD$，$BC \parallel AD$，且$PA = AB = \sqrt{2}$，$AD = 1 + \sqrt{3}$，建立空间直角坐标系如下图所示，设$A(0,0,0)$，$B(\sqrt{2},0,0)$，$C(\sqrt{2},2,0)$，$D(0,1+\sqrt{3},0)$，$P(0,0,\sqrt{2})$。{6.0cm}{4.001bp 4.001bp 4.001bp 4.001bp}在平面$xOy$中，线段$BC$的垂直平分线为$y=1$. 线段$CD$中点为$F\left(\frac{\sqrt{2}}{2},\frac{\sqrt{3}+3}{2}\right)$，直线$CD$的斜率为$-\frac{\sqrt{3}-1}{\sqrt{2}}$，故其垂直平分线的斜率为$\frac{\sqrt{2}}{\sqrt{3}-1}=\frac{\sqrt{6}+\sqrt{2}}{2}$，方程为$y-\frac{\sqrt{3}+3}{2}=\frac{\sqrt{6}+\sqrt{2}}{2}\left(x-\frac{\sqrt{2}}{2}\right)$. 联立$y=1$，解得$x=0$，所以$\triangle BCD$的外心为$O_0(0,1,0)$. 由$|O_0P| = \sqrt{0^2 + 1^2 + (0-\sqrt{2})^2} = \sqrt{3}$|O_0B| = \sqrt{(0-\sqrt{2})^2 + 1^2 + 0^2} = \sqrt{3}$|O_0C| = \sqrt{(0-\sqrt{2})^2 + (1-2)^2 + 0^2} = \sqrt{3}$$|O_0D| = \sqrt{0^2 + (1-1-\sqrt{3})^2 + 0^2} = \sqrt{3}$所以$|O_0P|=|O_0B|=|O_0C|=|O_0D|=\sqrt{3}$，故$O_0$即球心$O$，且点$O$在平面$ABCD$上。$法二$因为$P$，$B$，$C$，$D$在同一个球面上，所以球心到四个点的距离相等. 在$\triangle BCD$中，到三角形三点距离相等的点是该三角形的外心. 作出$BC$和$CD$的垂直平分线，如下图所示：由几何知识得$O_1E = AB = \sqrt{2}$，$BE = CE = AO_1 = \frac{1}{2} BC = 1$，$O_1D = AD - AO_1 = \sqrt{3}$， 并且$BO_1 = CO_1 = \sqrt{1^2 + (\sqrt{2})^2} = \sqrt{3}$，$O_1D = BO_1 = CO_1$， 所以点$O_1$是$\triangle BCD$的外心。在$\mathrm{Rt} \triangle AOP$中，$AP \perp AD$，$AP = \sqrt{2}$，故$PO_1 = \sqrt{AP^2 + AO_1^2} = \sqrt{(\sqrt{2})^2 + 1^2} = \sqrt{3}$从而$PO_1 = BO_1 = CO_1 = O_1 D = \sqrt{3}$点$O_1$即为点$P$，$B$，$C$，$D$所在球的球心$O$. 此时点$O$在线段$AD$上，且$AD \subset \text{平面} ABCD$，所以点$O$在平面$ABCD$上. (2) 由题意及上述结论和图得，设直线$AC$与直线$PO$所成角为$\theta$。$法一$写出向量$\overrightarrow{AC} = (\sqrt{2},2,0)$，$\overrightarrow{PO} = (0,1,-\sqrt{2})$，则 \begin{align*} \cos\theta &= \frac{|\overrightarrow{AC}\cdot\overrightarrow{PO}|}{|\overrightarrow{AC}||\overrightarrow{PO}|} &= \frac{|0\cdot\sqrt{2}+1\cdot 2+(-\sqrt{2})\cdot 0|}{\sqrt{(\sqrt{2})^2+2^2+0^2}\cdot \sqrt{0^2+1^2+(-\sqrt{2})^2}} &= \frac{2}{\sqrt{6}\cdot\sqrt{3}}=\frac{\sqrt{2}}{3} \end{align*}$法二$由几何知识得，$PO = \sqrt{3}$，$AB \perp AD$，$BC \parallel AD$，所以$AB \perp BC$. 在$\mathrm{Rt} \triangle ABC$中，$AB = \sqrt{2}$，$BC = 2$，故$AC = \sqrt{AB^2 + BC^2} = \sqrt{(\sqrt{2})^2 + 2^2} = \sqrt{6}$过点$O$作$AC$的平行线，交$BC$的延长线为$C_1$，连接$AC_1$，$PC_1$，则$OC_1 = AC = \sqrt{6}$，直线$AC$与直线$PO$所成角即为$\triangle POC_1$中$\angle POC_1$或其补角。因为$PA \perp \text{平面} ABCD$，$AC_1 \subset \text{平面} ABCD$，所以$PA \perp AC_1$. 在$\mathrm{Rt} \triangle ABC_1$中，$AB = \sqrt{2}$，$BC_1 = BC + CC_1 = 2 + 1 = 3$，故$AC_1 = \sqrt{AB^2 + BC_1^2} = \sqrt{(\sqrt{2})^2 + 3^2} = \sqrt{11}$在$\mathrm{Rt} \triangle APC_1$中，$PA = \sqrt{2}$，故$PC_1 = \sqrt{PA^2 + AC_1^2} = \sqrt{(\sqrt{2})^2 + (\sqrt{11})^2} = \sqrt{13}$在$\triangle POC_1$中由余弦定理得$PC_1^2 = PO^2 + OC_1^2 - 2PO \cdot OC_1 \cos \angle POC_1 =(\sqrt{13})^2 = (\sqrt{3})^2 + (\sqrt{6})^2 - 2\sqrt{3}\sqrt{6}\cos \angle POC_1$故$\cos \angle POC_1 = -\frac{\sqrt{2}}{3}$， 所以直线$AC$与直线$PO$所成角的余弦值为$|\cos \angle POC_1| = \frac{\sqrt{2}}{3}$。
