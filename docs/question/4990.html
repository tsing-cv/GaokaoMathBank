题目 #15

2006年 · 2006年湖北卷（理） · 填空题 三角函数数列

将杨辉三角中的每一个数$\mathrm\{C\}_n^r$都换成分数$\frac\{1\}\{(n + 1)\mathrm\{C\}_n^r\}$，得到一个如图所示的分数三角形，称为莱布尼茨三角形。$\begin\{array\}\{ccccccccccccc\} &&&&&&\displaystyle\frac\{1\}\{1\}&&&&&&\\ &&&&&\displaystyle\frac\{1\}\{2\}&&\displaystyle\frac\{1\}\{2\}&&&&&\\ &&&&\displaystyle\frac\{1\}\{3\}&&\displaystyle\frac\{1\}\{6\}&&\displaystyle\frac\{1\}\{3\}&&&&\\ &&&\displaystyle\frac\{1\}\{4\}&&\displaystyle\frac\{1\}\{12\}&&\displaystyle\frac\{1\}\{12\}&&\displaystyle\frac\{1\}\{4\}&&&\\ &&\displaystyle\frac\{1\}\{5\}&&\displaystyle\frac\{1\}\{20\}&&\displaystyle\frac\{1\}\{30\}&&\displaystyle\frac\{1\}\{20\}&&\displaystyle\frac\{1\}\{5\}&&\\ &\displaystyle\frac\{1\}\{6\}&&\displaystyle\frac\{1\}\{30\}&&\displaystyle\frac\{1\}\{60\}&&\displaystyle\frac\{1\}\{60\}&&\displaystyle\frac\{1\}\{30\}&&\displaystyle\frac\{1\}\{6\}&\\\displaystyle\frac\{1\}\{7\}&&\displaystyle\frac\{1\}\{42\}&&\displaystyle\frac\{1\}\{105\}&&\displaystyle\frac\{1\}\{140\}&&\displaystyle\frac\{1\}\{105\}&&\displaystyle\frac\{1\}\{42\}&&\displaystyle\frac\{1\}\{7\}\\ \cdots\cdots \end\{array\}$从莱布尼茨三角形可看出$\frac\{1\}\{(n + 1)\mathrm\{C\}_n^\{r\}\} + \frac\{1\}\{(n + 1)\mathrm\{C\}_n^\{x\}\} = \frac\{1\}\{n\mathrm\{C\}_\{n - 1\}^\{r\}\}$，其中$x =$____，令$a_n = \frac\{1\}\{3\} + \frac\{1\}\{12\} + \cdots + \frac\{1\}\{n\mathrm\{C\}_\{n - 1\}^\{2\}\} + \frac\{1\}\{(n + 1)\mathrm\{C\}_n^\{2\}\}$，则$\lim\limits_\{n\to \infty\} a_n =$____。
答案与解析
答案:
$r+1$，$\frac{1}{2}$
解析:
莱布尼茨三角形中同一行相邻两项之和等于上一行夹在它们正上方的项，因此右边一项的组合数下标比左边一项大$1$，故$x=r+1$. 由组合数的对称性，给出的和可写为$a_n=\sum_\{j=2\}^\{n\}\frac\{1\}\{(j+1)\mathrm C_\{j\}^\{2\}\}$又$\mathrm C_j^2=\frac\{j(j-1)\}\{2\}$，所以$\frac\{1\}\{(j+1)\mathrm C_j^2\}=\frac\{2\}\{j(j-1)(j+1)\}=\frac\{1\}\{j(j-1)\}-\frac\{1\}\{j(j+1)\}$从而$a_n=\sum_\{j=2\}^\{n\}\left(\frac\{1\}\{j(j-1)\}-\frac\{1\}\{j(j+1)\}\right)=\frac12-\frac\{1\}\{n(n+1)\}$令$n\to\infty$，得到$\lim\limits_\{n\to\infty\}a_n=\frac12$。
