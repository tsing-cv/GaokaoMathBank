题目 #17

2009年 · 2009年湖北卷（理） · 解答题 三角函数向量

已知向量$\vec{a} = (\cos \alpha, \sin \alpha)$，$\vec{b} = (\cos \beta, \sin \beta)$，$\vec{c} = (-1, 0)$. (1) 求向量$\vec{b} + \vec{c}$的长度的最大值； (2) 设$\alpha = \frac{\pi}{4}$，且$\vec{a} \perp (\vec{b} + \vec{c})$，求$\cos \beta$的值。
答案与解析
解析:
(1)$\left\lvert\vec{b}+\vec{c}\right\rvert^\{2\}=(\cos\beta-1)^\{2\}+\sin^\{2\}\beta=2-2\cos\beta$因为$\cos\beta\geqslant-1$，所以$\left\lvert\vec{b}+\vec{c}\right\rvert^\{2\}\leqslant4$从而向量$\vec{b}+\vec{c}$的长度的最大值为$2$，且在$\cos\beta=-1$时取得. (2) 当$\alpha=\frac{\pi}{4}$时，$\vec{a}=\left(\frac{\sqrt{2}}{2},\frac{\sqrt{2}}{2}\right)$. 由垂直条件，得$0=\vec{a}\cdot(\vec{b}+\vec{c})=\frac{\sqrt{2}}{2}(\cos\beta-1+\sin\beta)$即$\cos\beta+\sin\beta=1$. 又因为$(\cos\beta+\sin\beta)^{2}=\cos^{2}\beta+\sin^{2}\beta+2\sin\beta\cos\beta$所以$\sin\beta\cos\beta=0$. 结合$\cos\beta+\sin\beta=1$，得到$(\cos\beta,\sin\beta)=(1,0)$或$(\cos\beta,\sin\beta)=(0,1)$. 故$\cos\beta=1$或$0$。
