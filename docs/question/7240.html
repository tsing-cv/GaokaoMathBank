题目 #20

2009年 · 2009年福建卷（理） · 解答题 函数导数

已知函数$f(x) = \frac{1}{3} x^3 + ax^2 + bx$，且$f'(-1) = 0$. (1) 试用含$a$的代数式表示$b$，并求$f(x)$的单调区间； (2) 令$a = -1$，设函数$f(x)$在$x_1$，$x_2$（$x_1 < x_2$）处取得极值，记点$M(x_1, f(x_1))$，$N(x_2, f(x_2))$，$P(m, f(m))$，$x_1 < m < x_2$. 请仔细观察曲线$f(x)$在点$P$处的切线与线段$MP$的位置变化趋势，并解释以下问题： (1) 若对任意的$m \in (t, x_2]$，线段$MP$与曲线$f(x)$均有异于$M$，$P$的公共点，试确定$t$的最小值，并证明你的结论； (2) 若存在点$Q(n, f(n))$，$x_1 \leqslant n < m$，使得线段$PQ$与曲线$f(x)$有异于$P$，$Q$的公共点，请直接写出$m$的取值范围. （不必给出求解过程）
答案与解析
解析:
(1) 由$f'(x)=x^2+2ax+b$，$f'(-1)=1-2a+b=0$得$b=2a-1$。 于是$f'(x)=x^2+2ax+2a-1=(x+1)(x+2a-1)=(x+1)(x-(1-2a))$当$a>1$时，$1-2a<-1$，故$f'(x)$在$(-\infty,1-2a)$和$(-1,+\infty)$上为正，在$(1-2a,-1)$上为负。 因此增区间为$(-\infty,1-2a)$和$(-1,+\infty)$，减区间为$(1-2a,-1)$. 当$a=1$时，$f'(x)=(x+1)^2\geqslant0$，所以$f(x)$在$\R$上单调递增. 当$a<1$时，$-1<1-2a$，故$f'(x)$在$(-\infty,-1)$和$(1-2a,+\infty)$上为正，在$(-1,1-2a)$上为负。 因此增区间为$(-\infty,-1)$和$(1-2a,+\infty)$，减区间为$(-1,1-2a)$. (2) 令$a=-1$，则$b=-3$，故$f(x)=\frac{1}{3}x^3-x^2-3x$，$f'(x)=(x+1)(x-3)$，所以$x_1=-1$，$x_2=3$. 对曲线上横坐标为$u$，$v$的两个点作割线。 由于$f(x)$的三次项系数为$\frac{1}{3}$，割线方程与曲线方程相减后所得三次方程的三个根为$u$，$v$，$w$。 该三次方程的首项为$\frac{1}{3}x^3$，而二次项系数为$-1$，与$\frac{1}{3}(x-u)(x-v)(x-w)$比较可得$-\frac{u+v+w}{3}=-1$，即$u+v+w=3$，所以第三个交点的横坐标为$w=3-u-v$. (1) 取$u=x_1=-1$，$v=m$，得$w=4-m$。 当$m\in(t,3]$时，线段$MP$与曲线有异于$M$，$P$的公共点，要求第三个交点的横坐标满足$-12$； 当$m=3$时仍有$w=1$，满足条件。 因此对所有$m\in(2,3]$均成立，而任意$t<2$都会使$m=2$落入$(t,3]$，此时$w=m$并无异于$P$的第三个交点。 故$t$的最小值为$2$. (2) 取$u=n$，$v=m$，第三个交点横坐标为$w=3-m-n$。 它位于线段$PQ$内部当且仅当$n<3-m-n
