题目 #15

2013年 · 2013年安徽卷（文） · 填空题 集合与逻辑立体几何

如图，正方体$ABCD - A_{1}B_{1}C_{1}D_{1}$的棱长为$1$，$P$为$BC$中点，$Q$为线段$CC_{1}$上的动点，过$A$，$P$，$Q$的平面截该正方体所得的截面记为$S$，则下列命题正确的是____.（写出所有正确命题的编号）① 当$0 < CQ < \frac{1}{2}$时，$S$为四边形； ② 当$CQ = \frac{1}{2}$时，$S$为等腰梯形； ③ 当$CQ = \frac{3}{4}$时，$S$与$C_1D_1$交点$R$满足$C_1R = \frac{1}{3}$； ④ 当$\frac{3}{4} < CQ < 1$时，$S$为六边形； ⑤ 当$CQ = 1$时，$S$的面积为$\frac{\sqrt{6}}{2}$。
答案与解析
答案:
$(1)(2)(3)(5)$
解析:
令$t=CQ$，建立坐标系$A=(0,0,0)$，$B=(1,0,0)$，$C=(1,1,0)$，$D=(0,1,0)$$A_1=(0,0,1)$，$B_1=(1,0,1)$，$C_1=(1,1,1)$，$D_1=(0,1,1)$. 于是$P=(1,\frac12,0)$，$Q=(1,1,t)$，平面$APQ$的方程为$tx-2ty+z=0$，$z=t(2y-x)$. 当$0<t<\frac12$时，平面与正方体的截面依次经过$A$，$P$，$Q$及$DD_1$上的点$(0,1,2t)$，所以截面为四边形，命题$(1)$正确. 当$t=\frac12$时，该点为$D_1$，截面为四边形$APQD_1$. 其中$PQ\parallel AD_1$，且$|AP|=\sqrt{1+\frac14}=|QD_1|$所以它是等腰梯形，命题$(2)$正确. 当$t=\frac34$时，截面与上棱$C_1D_1$的交点$R=(r,1,1)$满足$\frac34(2-r)=1$，$r=\frac23$. 因此$C_1R=1-r=\frac13$，命题$(3)$正确. 当$\frac34<t<1$时，截面顶面上的两个交点为$R=\left(2-\frac1t,1,1\right)$，$U=\left(0,\frac1{2t},1\right)$截面依次经过$A$，$P$，$Q$，$R$，$U$，是五边形而不是六边形，命题$(4)$错误. 当$t=1$时，$Q=C_1$，且$U=(0,\frac12,1)$，截面为四边形$APC_1U$. 将其分成三角形$APC_1$和$AC_1U$，有$\overrightarrow{AP}=\left(1,\frac12,0\right)$，$\overrightarrow{AC_1}=(1,1,1)$，$\overrightarrow{AU}=\left(0,\frac12,1\right)$且$\left|\overrightarrow{AP}\times\overrightarrow{AC_1}\right| =\left|\overrightarrow{AC_1}\times\overrightarrow{AU}\right|=\frac{\sqrt6}{2}$所以截面面积为$\frac12\cdot\frac{\sqrt6}{2}+\frac12\cdot\frac{\sqrt6}{2}=\frac{\sqrt6}{2}$命题$(5)$正确. 故正确命题的编号为$1$，$2$，$3$，$5$。
