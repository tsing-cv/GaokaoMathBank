题目 #3

2011年 · 2011年陕西卷（文） · 选择题 不等式

设$0 < a < b$，则下列不等式中正确的是（ ）
A.
$a < b < \sqrt{ab} < \frac{a + b}{2}$
B.
$a < \sqrt{ab} < \frac{a + b}{2} < b$
C.
$a < \sqrt{ab} < b < \frac{a + b}{2}$
D.
$\sqrt{ab} < a < \frac{a + b}{2} < b$
答案与解析
答案:
B
解析:
由$0<a<b$，并且平方根函数在正数上单调递增，有$a^2<ab<b^2$，$\Longrightarrow$，$a<\sqrt{ab}<b$另外，$\frac{a+b}{2}-\sqrt{ab}=\frac{(\sqrt b-\sqrt a)^2}{2}>0$所以$\sqrt{ab}<\frac{a+b}{2}$. 又因$a<b$，有$\frac{a+b}{2}<b$. 合并得$a<\sqrt{ab}<\frac{a+b}{2}<b$故选 B。
