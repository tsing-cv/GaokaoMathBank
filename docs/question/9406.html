题目 #10

2011年 · 2011年浙江卷（理） · 选择题 集合与逻辑

设$a$，$b$，$c$为实数，$f(x) = (x + a)(x^2 + bx + c)$，$g(x) = (ax + 1)(cx^2 + bx + 1)$. 记集合$S = \{x \mid f(x) = 0, x \in \R\}$，$T = \{x \mid g(x) = 0, x \in \R\}$，若$|S|$，$|T|$分别为集合$S$，$T$的元素个数，则下列结论不可能的是（ ）
A.
$|S| = 1$且$|T| = 0$
B.
$|S| = 1$且$|T| = 1$
C.
$|S| = 2$且$|T| = 2$
D.
$|S| = 2$且$|T| = 3$
答案与解析
答案:
D
解析:
对任意$x\neq 0$，有$x^3f\left(\frac{1}{x}\right)=x^3\left(\frac{1}{x}+a\right)\left(\frac{1}{x^2}+\frac{b}{x}+c\right)=(ax+1)(cx^2+bx+1)=g(x)$又因为$g(0)=1$，所以$T$中的每个元素都不为零. 于是若$x\in T$，则$f(1/x)=0$，从而$1/x\in S$. 映射$x\mapsto 1/x$是单射，因此$\lvert T\rvert\leqslant\lvert S\rvert$，选项 D 中$\lvert T\rvert=3>2=\lvert S\rvert$，不可能. 其余三项确实可以取得. 例如$(a,b,c)=(0,0,0)$时$(\lvert S\rvert,\lvert T\rvert)=(1,0)$；$(a,b,c)=(1,0,1)$时$(\lvert S\rvert,\lvert T\rvert)=(1,1)$；$(a,b,c)=(1,3,2)$时$f(x)=(x+1)^2(x+2)$，$g(x)=(x+1)^2(2x+1)$故$(\lvert S\rvert,\lvert T\rvert)=(2,2)$. 因此故选 D。
