题目 #22

2008年 · 2008年福建卷（理） · 解答题 函数导数数列

已知函数$f(x) = \ln (1 + x) - x$. (1) 求$f(x)$的单调区间； (2) 记$f(x)$在区间$[0, \pi]$（$n \in \N^*$）上的最小值为$b_n$，令$a_n = \ln(1 + n) - b_n$. (1) 如果对一切$n$，不等式$\sqrt{a_n} < \sqrt{a_{n+2}} - \frac{c}{\sqrt{a_{n+2}}}$恒成立，求实数$c$的取值范围； (2) 求证：$\frac{a_1}{a_2} + \frac{a_1a_3}{a_2a_4} + \dots + \frac{a_1a_3\cdots a_{2n-1}}{a_2a_4\cdots a_{2n}} < \sqrt{2a_n + 1} -1$。
答案与解析
解析:
(1) 函数定义域为$(-1,+\infty)$，且$f'(x)=\frac{1}{1+x}-1=-\frac{x}{1+x}$当$-1<x<0$时，$f'(x)>0$； 当$x>0$时，$f'(x)<0$. 因此$f(x)$在$(-1,0)$上单调递增，在$(0,+\infty)$上单调递减. (2) 因为$f(x)$在$[0,+\infty)$上单调递减，所以对任意$n\in\N^*$，其在$[0,\pi]$上的最小值为$b_n=f(\pi)=\ln(1+\pi)-\pi$令$d=\pi-\ln(1+\pi)>0$则$a_n=\ln(1+n)-b_n=d+\ln(1+n)>0$(1) 因为$a_{n+2}>a_n>0$，原不等式等价于$c<a_{n+2}-\sqrt{a_na_{n+2}}=:h_n$又$h_n=(a_{n+2}-a_n)\frac{\sqrt{a_{n+2}}}{\sqrt{a_{n+2}}+\sqrt{a_n}}$所以$0<h_n<a_{n+2}-a_n=\ln\frac{n+3}{n+1}$由$\displaystyle\lim_{n\to+\infty}\ln\frac{n+3}{n+1}=0$，若$c>0$，则对充分大的$n$有$h_n<c$，原不等式不能对一切$n$成立. 若$c\leqslant0$，则$c<h_n$对一切$n\in\N^*$成立. 因此$c\in(-\infty,0]$(2) 按原题面，第二问中的不等式并不成立. 取$n=2$. 先用$3.14<\pi<3.15$、$1.42<\ln(1+\pi)<1.43$得$1.71<d<1.73$，再用$0.69<\ln2<0.70$、$1.09<\ln3<1.10$、$1.38<\ln4<1.39$、$1.60<\ln5<1.61$，得到$2.40<a_1<2.43$，$2.80<a_2<2.83$，$3.09<a_3<3.12$，$3.31<a_4<3.34$. 所有这些数均为正，因此左端满足$\frac{a_1}{a_2}+\frac{a_1a_3}{a_2a_4}>\frac{2.40}{2.83}+\frac{2.40\times3.09}{2.83\times3.34}>1.63$而右端满足$\sqrt{2a_2+1}-1<\sqrt{2\times2.83+1}-1=\sqrt{6.66}-1<2.59-1=1.59$所以左端大于右端，所要求证的不等式在$n=2$时已经不成立. 因此按原题清晰题面，第二问存在排印或版本错误，不能给出其所要求的不等式证明。
