题目 #20

2015年 · 2015年山东卷（文） · 解答题 函数导数

设函数$f(x) = (x + a)\ln x$，$g(x) = \frac\{x^2\}\{e^x\}$. 已知曲线$y = f(x)$在点$(1, f(1))$处的切线与直线$2x - y = 0$平行. (1) 求$a$的值； (2) 是否存在自然数$k$，使得方程$f(x) = g(x)$在$(k, k + 1)$内存在唯一的根？ 如果存在，求出$k$；如果不存在，请说明理由； (3) 设函数$m(x) = \min \\{f(x), g(x)\\}$（$\min \\{p, q\\}$表示$p$，$q$中的较小值），求$m(x)$的最大值。
答案与解析
解析:
(1)$f(x)=(x+a)\ln x$的导数为$f'(x)=\ln x+1+\frac ax$，所以$f'(1)=1+a$. 直线$2x-y=0$的斜率为$2$，由切线平行条件得$1+a=2$，即$a=1$. (2) 此时$f(x)=(x+1)\ln x$，令$h(x)=f(x)-g(x)=(x+1)\ln x-x^2e^\{-x\}$其中$x>0$. 当$0\frac12$且$e>2$，所以$h(2)=3\ln2-\frac4\{e^2\}>\frac32-1>0$，故在$(1,2)$内至少有一个根. 对$x\geqslant1$，有$h'(x)=\ln x+1+\frac1x-x(2-x)e^\{-x\}$当$1\leqslant x\leqslant2$时，$x(2-x)\leqslant1$，故$h'(x)\geqslant1-e^\{-1\}>0$； 当$x\geqslant2$时，$x(2-x)\leqslant0$，也有$h'(x)>0$. 因此$h(x)$在$[1,+\infty)$上严格递增，方程在$(1,2)$内恰有一个根，并且在其余$(k,k+1)$（$k\geqslant2$）内没有根. 所以存在的自然数为$k=1$. (3) 仍令$\alpha$为$(1,2)$内唯一满足$f(\alpha)=g(\alpha)$的根. 当$00$，此时$m(x)$递增. 当$x\geqslant\alpha$时，$m(x)=g(x)=x^2e^\{-x\}$，且$g'(x)=x(2-x)e^\{-x\}$所以$g(x)$在$(0,2)$上递增、在$(2,+\infty)$上递减. 因为$\alpha<2$，$m(x)$的最大值在$x=2$处取得，最大值为$m(2)=g(2)=\frac4\{e^2\}$
