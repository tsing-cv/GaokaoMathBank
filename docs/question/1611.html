题目 #24

1989年 · 1989年全国卷（理） · 解答题 集合与逻辑函数三角函数

设$f(x)$是定义在区间$(-\infty, +\infty)$上以$2$为周期的函数，对$k \in \Z$，用$I_k$表示区间$(2k - 1, 2k + 1]$，已知当$x \in I_0$时，$f(x) = x^2$. (1) 求$f(x)$在$I_k$上的解析表达式； (2) 对自然数$k$，求集合$M_k = \left\{ a \mid \text{使方程 } f(x) = ax \text{ 在 } I_k \text{ 上有两个不等的实根} \right\}$。
答案与解析
解析:
(1) 当$x\in I_k=(2k-1,2k+1]$时，减去$2k$得$x-2k\in(-1,1]=I_0$. 由周期性$f(x)=f(x-2k)$，再利用$f(t)=t^2$（$t\in I_0$），可得$f(x)=(x-2k)^2$，$x\in I_k$. (2) 先按通常约定的正自然数$k=1$，$2$，$\ldots$讨论. 令$t=x-2k$，则$t\in(-1,1]$，且$x=2k+t>0$. 因而当$a<0$时，方程左边$t^2\geqslant0$，右边$a(2k+t)<0$，没有实根； 当$a=0$时方程化为$t^2=0$，只有一个实根. 对$a>0$，方程$f(x)=ax$等价于$t^2=a(2k+t),\qquad\text{即}\qquad a=h(t):=\frac{t^2}{2k+t}$在$(-1,1]$上分母$2k+t\geqslant2k-1>0$，并且$h'(t)=\frac{t(4k+t)}{(2k+t)^2}$因为$k\geqslant1$，所以$4k+t>0$，从而$h(t)$在$(-1,0)$上递减，在$(0,1]$上递增. 并且$\lim_{t\to-1^+}h(t)=\frac{1}{2k-1}$，$h(0)=0$，$h(1)=\frac{1}{2k+1}$. 因为$t=-1$不在区间内而$t=1$在区间内，负半段$t\in(-1,0)$给出值域$\left(0,\frac{1}{2k-1}\right)$，正半段$t\in(0,1]$给出值域$\left(0,\frac{1}{2k+1}\right]$. 对同一个$a>0$，两个值域的交集分别在负、正两段各给出一个根，且两根不相等； 反之，若$a$不在交集中，就不可能在两段各有一个根. 因此方程有两个不等的实根，当且仅当$0
