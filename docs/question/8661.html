题目 #20

2010年 · 2010年浙江卷（理） · 解答题 三角函数立体几何

如图，在矩形$ABCD$中，点$E$，$F$分别在线段$AB$，$AD$上，$AE = EB = AF = \frac{2}{3} FD = 4$. 沿直线$EF$将$\triangle AEF$翻折成$\triangle A'EF$，使平面$A'EF \perp$平面$BEF$. (1) 求二面角$A' - FD - C$的余弦值； (2) 点$M$，$N$分别在线段$FD$，$BC$上，若沿直线$MN$将四边形$MNCD$向上翻折，使$C$与$A'$重合，求线段$FM$的长。
答案与解析
解析:
建立直角坐标系，使矩形所在平面为$z=0$，取$D=(0,0,0)$，$F=(0,6,0)$，$A=(0,10,0)$，$B=(8,10,0)$C=(8,0,0)$，$E=(4,10,0)$. 这里由$\frac23FD=4$得$FD=6$. 设$H$为$EF$的中点，则$H=(2,8,0)$. 因为$AE=AF$，所以$AH\perp EF$，且$AH=2\sqrt2$. 折叠后平面$A'EF$与原平面垂直，故可取$A'=(2,8,2\sqrt2)$(1) 平面$FDC$是$z=0$，可取其法向量$\bs{n}_2=(0,0,1)$. 平面$A'FD$内的两个方向向量可取$\overrightarrow{FD}=(0,-6,0)$和$\overrightarrow{FA'}=(2,2,2\sqrt2)$，故其法向量可取$\bs{n}_1=\overrightarrow{FD}\times\overrightarrow{FA'}=(-12\sqrt2,0,12)$因此二面角的余弦值为$\frac{|\bs{n}_1\cdot\bs{n}_2|}{|\bs{n}_1||\bs{n}_2|} =\frac{12}{\sqrt{(12\sqrt2)^2+12^2}}=\frac{\sqrt3}{3}$(2) 设$FM=x$，则$M=(0,6-x,0)$，且$0\leqslant x\leqslant6$. 折叠绕直线$MN$进行，点$M$在折痕上不动，所以$CM=A'M$. 于是$CM^2=8^2+(6-x)^2$A'M^2=2^2+(8-(6-x))^2+(2\sqrt2)^2=(x+2)^2+12$令两式相等，得$64+(6-x)^2=(x+2)^2+12$，$x=\frac{21}{4}$. 还需验证折痕可取在$BC$上. 令$N=(8,n,0)$，由$CN=A'N$得$n^2=6^2+(n-8)^2+(2\sqrt2)^2$故$n=\frac{27}{4}\in[0,10]$，确有$N\in BC$. 所以$FM=\frac{21}{4}$
