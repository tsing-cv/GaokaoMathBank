题目 #12

1977年 · 1977年新疆卷（理） · 解答题 三角函数

已知$0^\circ<x<45^\circ$，且有$\lg\tan x-\lg\sin x=\lg\cos x-\lg\cot x+2\lg3-\frac32\lg2$，试求$\sin x-\cos x$的值。
答案与解析
解析:
由$0^\circ<x<45^\circ$，知$\sin x>0$、$\cos x>0$、$\tan x>0$、$\cot x>0$，所以题中各个对数均有意义. 利用对数的商的运算性质和$\tan x=\frac{\sin x}{\cos x}$，左边为$\lg\tan x-\lg\sin x =\lg\frac{\tan x}{\sin x} =\lg\frac{1}{\cos x}$右边利用$\cot x=\frac{\cos x}{\sin x}$、$2\lg3=\lg9$和$\frac32\lg2=\lg2^{\frac32}=\lg(2\sqrt2)$，得$\lg\cos x-\lg\cot x+2\lg3-\frac32\lg2 =\lg\frac{\cos x}{\cot x}+\lg9-\lg(2\sqrt2) =\lg\frac{9\sin x}{2\sqrt2}$因此$\lg\frac1{\cos x}=\lg\frac{9\sin x}{2\sqrt2}$两边真数均为正，且$\lg t$在正数范围内为一一对应函数，故$\frac1{\cos x}=\frac{9\sin x}{2\sqrt2}$，$\sin x\cos x=\frac{2\sqrt2}{9}$. 由$0^\circ<x<45^\circ$得$\sin x<\cos x$，所以$\sin x-\cos x<0$. 又$\left(\sin x-\cos x\right)^2 =\sin^2x+\cos^2x-2\sin x\cos x =1-2\sin x\cos x =1-\frac{4\sqrt2}{9}$于是$\sin x-\cos x=-\sqrt{1-\frac{4\sqrt2}{9}} =-\frac{\sqrt{9-4\sqrt2}}{3}$注意到$9-4\sqrt2=(2\sqrt2-1)^2$，且$2\sqrt2-1>0$，所以$\sin x-\cos x=-\frac{2\sqrt2-1}{3}=\frac{1-2\sqrt2}{3}$
